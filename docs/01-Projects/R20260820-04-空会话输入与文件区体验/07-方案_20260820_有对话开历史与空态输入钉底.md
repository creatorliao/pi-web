## 1. 综合规则（覆盖 02 §1 空态行）

| 工作区 / 动作 | 应该看见 |
|---------------|----------|
| 进入后打开了某条对话（恢复或点选） | 对话在主列；**桌面历史侧栏打开** |
| 无历史，或点了「新建」 | 标题在上、中间留白、**输入在底部**；历史开合保持人上次的状态 |

不另做开关。不把 ChatWindow 换父节点。

## 2. 施工

### 2.1 有对话 → 开历史（`AppShell`）

`selectedSession` 有值且非手机时 `setAgentHistoryOpen(true)`。依赖 `selectedSession?.id`：

- 恢复 / 点选 / `?session=` 都会开。
- 同一条会话对象被列表刷新替换时不重开。
- 用户点图标或拖过阈值收起后，保持收起，直到换一条会话。

### 2.2 空态输入钉底（`ChatWindow` + `globals.css`）

`isEmptyNew` 结构：

1. `chat-empty-composer-brand`：π / Pi Web / 版本（不和输入粘在一起）
2. `chat-empty-composer-spacer`：`flex: 1`
3. `chat-empty-composer-inner`：现有 `ChatInput` + 扩展状态条

宽度不另加 960；`ChatInput` 已是 `maxWidth: 820` + 左右 16。

## 3. 价值观

| 原则 | 本方案 |
|------|--------|
| 好上手 | 有对话就能看见列表换一条；输入位置空/满一致，跟常见聊天窗 |
| 不加戏 | 不新增「记住侧栏」开关；不把空态做成第二套居中卡片 |

## 4. 验收

| # | 步骤 | 期望 |
|---|------|------|
| V7 | 进入有历史的工作区（或点开一条） | 桌面历史侧栏打开 |
| V8 | 打开对话后手动收起历史，等侧栏刷新 | 仍收着 |
| V9 | 无历史工作区，或点「新建」 | 输入在列底，不是靠上或垂直居中 |
