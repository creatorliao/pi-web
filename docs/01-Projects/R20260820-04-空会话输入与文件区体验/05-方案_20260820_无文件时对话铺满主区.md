## 1. 推荐（R-03 2B 的落地版）

不换布局设置、不把 `ChatWindow` 搬到另一个 React 父节点（打开文件会丢掉流式/滚动）。

```text
编辑器 + 无页签    左目录 | 对话（铺满剩余宽度，历史抽屉仍在对话块里）
编辑器 + 有页签    左目录 | 文件 | 对话（辅栏原宽）
助手模式           不动（本来中槽就是对话；无文件时右槽已收起）
```

做法：`editorChatExpanded = 桌面编辑器 && fileTabs.length === 0`

- 主栏（空文件工作区 + 空页签顶栏）仅在对话栏仍开着时 `display: none`（`editorChatFills`）。左右开合搬到对话顶栏，见 [R-03 14](../R20260819-03-界面Cursor化布局/14-方案_20260820_左右侧栏开合对称.md)。
- 辅栏加 `right-panel-fill`：`flex: 1`，不再用固定 `--right-panel-width`
- 分栏拖条关掉（旁边没有文件栏）
- 打开第一个文件：主栏回来，辅栏回到记住的宽度；对话仍挂在辅栏，不重挂

对照：助手模式无文件已经收起右槽。编辑器无文件应对称——收起**空文件槽**，不是收起对话。

## 2. 不选的路

| 方案 | 为何不做 |
|------|----------|
| 自动改 `layoutMode` 成助手 | 改用户设置；打开文件还要改回来，加戏 |
| 把 `agentWorkspace` 挪到主栏 JSX | 换父节点会卸挂 ChatWindow，生成中/草稿滚动会丢 |
| 空中槽再画一套输入框 | 两套 Composer，不加戏 |

## 3. In / Out

| In | Out |
|----|-----|
| 编辑器无页签时对话铺满 | 改出厂默认布局 |
| 打开/关光文件时回切，不重挂对话 | 文件树绿点（另题） |
| 窄桌面 overlay 在铺满态改为参与 flex | 第三种布局名字 |
