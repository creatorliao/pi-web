## 2. 问题清单

### PR-06 打开对话后历史抽屉仍收着

- **表层现象**：已经在看某条对话，右侧历史列表默认关着，要再点一次才看得到「近 7 天」。
- **直接原因**：`agentHistoryOpen` 默认 `false`（R-03：列表默认收起，先看当前对话）。
- **根本原因**：把「少占一栏」放在「有对话就该能换对话」前面。有会话时列表是主路径的一部分，不是额外一层。
- **修复方向**：桌面下 `selectedSession` 从无到有（或换一条）时 `setAgentHistoryOpen(true)`。只跟会话 id 走，人自己收起后不要被列表刷新再撑开。手机仍是整页抽屉，不自动开。点「新建」不必强关。
- **是否临时缓解**：否

### PR-07 空会话 Composer 靠上，和有消息时不在同一位置

- **表层现象**：无历史或点「新建」后，输入框在标题正下方靠上；有消息时同一输入框在列底。换场景要重新找手的位置。
- **直接原因**：`isEmptyNew` 用 `chat-empty-composer` 顶对齐 + `padding-top: 48px`（本夹 WP-B）。
- **根本原因**：空态按「欢迎海报 / 马上开写」单独排了一套，没有跟进行中对话共用「输入永远在底」的习惯。
- **修复方向**：空态标题仍可留在顶部；中间弹性留白；Composer 钉底。宽度继续交给 `ChatInput` 的 820，不再另做 960 靠上卡片。
- **是否临时缓解**：否
