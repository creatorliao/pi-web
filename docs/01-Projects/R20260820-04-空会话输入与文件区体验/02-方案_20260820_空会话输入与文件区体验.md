## 1. 一条规则（综合考量）

```text
进入工作区
  ├─ 有历史：打开上次对话（记忆优先，否则该工作区 modified 最新）
  └─ 无历史 / 人点了新建：空输入框靠顶部，宽度适合输入
打开文件
  └─ 细栏：原文|预览|差异（中文）· 字号 A− A+ · 无绿点
```

不把「空输入框好看」和「有历史还空着」当成两件无关的事：空态只服务真·无对话。

## 2. WP 拆分

| WP | 改什么 | 验收要点 |
|----|--------|----------|
| **A** | `pickWorkspaceSessionToRestore` + `restoreWorkspaceContext` 始终查列表 | 有历史必打开一条；记忆仍优先；新建/深链不抢 |
| **B** | `ChatWindow` 空态顶对齐、内宽 960 | 无历史/新建靠上；有消息列仍 820、输入在底 |
| **C** | `FileViewer` 文案 i18n、删绿点、字号步进 | 中文原文/预览/差异；无绿点；A± 改变正文并记住 |

## 3. 规格

### 3.1 恢复会话（WP-A）

纯函数（`lib/workspace-memory.ts`）：

1. 只在 `workspaceKeyOf(session) === projectKey` 的会话里挑。
2. `rememberedId` 仍在该集合 → 用它。
3. 否则取 `modified` 字典序最大的一条（与列表 API 已按 modified 降序一致）。
4. 集合空 → `null`（空态）。

`restoreWorkspaceContext`：**不再**因没有记忆而直接 return；拉 `/api/sessions` 后走上面的函数。列表失败（`d === null`）不清除记忆。选中后仍走现有 `setSelectedSession` + `sessionKey++` + `?session=`。

不改：点会话、点新建、`?session=` 深链、同一项目换 worktree 不重挂。

### 3.2 空态输入（WP-B）

仅 `isEmptyNew` 分支：

- 垂直：`justify-content: flex-start`，桌面 `padding-top: 48px`，窄屏 `24px`。
- 宽度：容器 `max-width: 960px`（有消息时正文仍 `820`）。
- 保留标题行与版本号；不新增教练文案。

对照 Cursor：空 Agent 输入在视口上半，而不是正中。

### 3.3 文件细栏（WP-C）

| 现在 | 之后 |
|------|------|
| 绿点 + `Source`/`Preview`/`Diff`（英文常量） | 无绿点；`t("i18n.source\|preview\|diff")` |
| 字号 13 写死 | 细栏 A− / 当前号 / A+；档位 12 / 13 / 14 / 16 / 18，默认 13 |
| 监视 SSE 画点 | SSE 仍刷新文件；不暴露 `watching` |

中文：原文 / 预览 / 差异。英文保持 Source / Preview / Diff（IDE 习惯）。

**不**把「原文」写成「编辑」：查看器只读。真编辑另立项。

字号写入 `localStorage` 键 `pi-web:file-viewer-zoom`。作用于源码、差异、Markdown 预览；HTML iframe 用 `zoom` 同比。图/音频/Office 预览不加 A±。

不把字号再做进设置「外观」（入口已在人指的细栏右上）。

## 4. 价值观对照

| 原则 | 本方案 |
|------|--------|
| 好上手 | 有内容的项目打开上次；空项目才空白输入靠上；细栏中文；字号在内容铬条 |
| 不加戏 | 不增加「自动进入」开关；不做编辑器；不设第二套字号设置；不解释绿点、直接删 |

## 5. 验收

| # | 步骤 | 期望 |
|---|------|------|
| V1 | 打开「尚无对话」的工作区 | 输入框在上半，不是垂直居中 |
| V2 | 打开有多条历史、本机从未记过上次的工作区 | 自动打开最近修改的那条，不是空输入 |
| V3 | 在项目 A 打开会话 S，切到 B 再回 A | 仍打开 S |
| V4 | 点「新建」 | 空输入靠上；不自动跳回历史 |
| V5 | 打开 Markdown | 细栏为「原文 / 预览」，无绿点 |
| V6 | 点 A+ / A− | 正文变大变小；刷新后仍是该档 |
