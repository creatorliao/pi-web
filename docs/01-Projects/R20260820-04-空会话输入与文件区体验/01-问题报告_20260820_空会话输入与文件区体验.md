## 1. 综合判断（先于单条）

进入工作区后只有两种正当画面，不要混：

| 工作区 | 人要完成的事 | 应该看见 |
|--------|--------------|----------|
| **没有**历史对话 | 开始第一句 | 输入框靠上、宽度够写；不要垂直居中的小岛 |
| **有**历史对话 | 接着上次做 | 打开上次对话（有记忆用记忆；没有则最近一条） |
| 人点了「新建」 | 另开一场 | 仍是靠上的空输入框，即使旁边已有历史 |

R-01 写过「恢复该项目上次会话，没有则空对话」。实现里「没有」被理解成「浏览器没记住」，不是「磁盘上没对话」。有历史的项目第一次在本机打开，仍会落到空输入框——这和「无历史才空态」拧着。

对照：Cursor / VS Code 打开有内容的项目会回到上次状态；空仓库才是空白编辑器。不另做「记住下次进入」开关（R-01 D2 不加戏仍成立）。

## 2. 问题清单

### PR-01 无历史时输入框垂直居中、显得窄

- **表层现象**：工作区没有任何历史对话时，输入框连同「π Pi Web」标题被垂直居中，像一张漂在空白里的卡片；写长句时宽度也不够用。
- **直接原因**：`ChatWindow` 空新会话分支用 `justify-center` + `max-w-[820px]`（`components/ChatWindow.tsx` `isEmptyNew`）。
- **根本原因**：空态按「欢迎海报」排，没按「马上要输入」排。有消息时 Composer 在底部、正文 `820px` 是阅读宽度；空态把同一套宽度再居中，视觉上更窄。
- **修复方向**：空态顶对齐、略加宽；有消息的对话列不动。
- **是否临时缓解**：否

### PR-02 有历史时仍可能落到空输入框

- **表层现象**：项目里明明有对话，进入后却是空输入框，要自己再点历史。有的工作区能打开，有的不能。
- **直接原因（第一层，已修）**：`restoreWorkspaceContext` 曾在没有 localStorage 记忆时直接 return。
- **直接原因（第二层，手验复现）**：欢迎页 `enterWorkspace` 先用稳定 `projectKey` 开始恢复；侧栏挂载后用 cwd 再报一次「换项目」。`handleCwdChange` **一进函数就** `invalidateWorkspaceRestore()`，把进行中的恢复作废，随后走「同 cwd 补 key」提前 return，不再恢复。`pickWorkspaceSessionToRestore` 又只认 `workspaceKeyOf === key`，cwd 对不上 `projectKey` 时集合为空。
- **根本原因**：把「侧栏身份补全」当成换工作区；用严格字符串当工作区身份。
- **修复方向**：有记忆且仍属于该工作区 → 打开它；否则打开该工作区 `modified` 最新的一条；真正零会话才空态。点「新建」、深链 `?session=` 不覆盖。
- **是否临时缓解**：否

### PR-03 文件区 Source / Preview 英文，且不像「能不能看原文」

- **表层现象**：中文界面细栏突然出现 `Source` / `Preview`；人关心的是「这是原文还是渲染」，不是编辑器术语。
- **直接原因**：`FileViewer.tsx` 用硬编码 `DISPLAY_MODE_LABELS`（英文），不走 `useI18n`。`zh-CN` 里已有 `i18n.source` =「源代码」、`i18n.diff` 仍是 `Diff`。
- **根本原因**：细栏当程序员向控件做（R-03 保留右侧切换），文案没跟界面语言走；「Source」对 Markdown 也不准（不是在编辑源码）。
- **修复方向**：走 i18n。中文：**原文 / 预览 / 差异**。不把只读审阅器标成「编辑」（本轮不做文件编辑器）。
- **是否临时缓解**：否

### PR-04 绿色连接点无操作、无信息增益

- **表层现象**：细栏左侧常亮绿点；默认就是连着的，点不了，也不知道能干什么。
- **直接原因**：四个查看器（图 / 音频 / 文档 / 文本）都画 `file-viewer-live-indicator`，绑定本地 `watching`。文件监视 SSE 本身仍在刷新内容。
- **根本原因**：把内部监视状态露成铬条装饰。人改不了、也用不上。
- **修复方向**：去掉绿点 UI；SSE 刷新逻辑保留。
- **是否临时缓解**：否

### PR-05 文件区文字不能调大调小

- **表层现象**：文件正文固定约 13px；设置页外观没有字号；人只能想到浏览器整页缩放。
- **直接原因**：`FILE_CODE_STYLE.fontSize = 13` 写死；设置「外观」只有主题 / 布局 / 提示音 / 隐藏文件 / 语言。
- **根本原因**：字号被当成实现细节，没有入口。通用软件把缩放放在内容区铬条或 View 菜单；本产品文件区铬条已有模式切换，缺的是字号，不是再开一页设置。
- **修复方向**：文件细栏右侧加 A− / A+（与 `@`、下载并列），只缩放文件正文；`localStorage` 记住。不进设置页（一套入口，不加戏）。
- **是否临时缓解**：否

## 3. In / Out Scope

| In | Out |
|----|-----|
| 空态 Composer 顶对齐与加宽 | 做 Markdown/源码真正可编辑保存 |
| 进入工作区：记忆 → 否则最近一条 → 否则空态 | 「下次自动进入项目」勾选（R-01 D2） |
| 细栏中文原文/预览/差异；去掉绿点 | 改三栏槽位、把控件搬回顶栏 |
| 文件区字号步进（正文） | 全局 UI 缩放、侧栏文件树字号、浏览器 Ctrl± 替代方案宣传 |
| 点「新建」仍空态 | 欢迎页卡片改版 |

---

## 4. 与既有决策的关系

- R-01「进入后恢复上次会话，没有则空对话」：**「没有」改为没有历史对话**，不是没有 localStorage。
- R-03 细栏右侧仍放模式切换 / `@` / 下载；只改文案、删绿点、加字号。
- 价值观：好上手（跟 IDE 打开项目的习惯）；不加戏（不新开设置项、不装编辑器、不教绿点是什么）。
