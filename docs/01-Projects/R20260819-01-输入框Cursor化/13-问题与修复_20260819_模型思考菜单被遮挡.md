# 问题与修复：模型×思考菜单被截断/遮挡

| 属性 | 值 |
|------|----|
| 日期 | 2026-08-19 |
| 状态 | 已施工 |
| 依据 | 用户截图 +「被遮挡了，应该是 z 轴的问题」 |

## 表层现象

成组触发器（`high · DeepSeek V4 Flash`）向上弹出的列表底部被切掉：最后一项「DeepSeek V4 Pro」缺底边，圆角和阴影不完整。

## 根因

菜单写在 Composer **卡片内部** `position: absolute; z-index: 100`。

1. **层叠被困住**：textarea 为叠在高亮层上设了 `z-index: 1`，在卡片这个层叠上下文里是 **1**。菜单的 100 只在铬条自己的 `z-index: auto` 子树里生效，整棵铬条仍低于 textarea。菜单往上长，下半截正好压在输入区上，被盖住。
2. **祖先裁剪加重**：空新会话容器是 `overflow-y-auto`，对话根是 `overflow-hidden`。绝对定位菜单只要冒出卡片，还会被裁。看起来像「崩坏截断」。

已有 `modelDropdownRect` 却没用，说明当初就想改视口定位，没做完。

## 修复

- 菜单 `createPortal` 到 `document.body`，`position: fixed`，按触发器 `getBoundingClientRect` 锚在上方，`z-index: 800`。
- 高度用已有 `getUpwardMenuMaxHeight`；超出则菜单自己滚动，不再被父级切平。
- 点菜单不误关：outside-click 排除 portal 节点。
- 样式：分区标题不再全大写挤在一起；档位名与说明紧挨（取消 `flex:1` 撑开的大空档）；行高与底边距收齐。
