## 0. 两层地面（与 R-13 必须同读）

Cursor / VS Code 是 **IDE 壳 + Composer**，不是一条工具栏。本仓按用户修订后的切法：

```text
Composer（已冻结，R-13 禁止再改）     窗口底栏 app-statusbar
模型 × 思考成组                       左：Git · 项目 · 对话分支（待做）
圆环 / 附件 / 发送↑ · 停止■           右：压缩 · 工具预设 · 喇叭（已落地）
```

压缩按钮已在底栏（R-13 D9），**不在**框内。框上方压缩结果/错误条仍属 Composer，维持原样。详见 [R-13 04-冻结](../R20260819-13-底部状态栏/04-方案修订_20260819_Composer冻结.md)。

| 控件 | 为什么在这层 |
|------|----------------|
| 模型、思考 | 写这一句提示时就要选「谁来答、想多深」→ Composer |
| **压缩按钮** | 已迁窗口底栏（R-13 D9）；Composer 只保留 `/compact` 与结果/错误条 |
| 圆环、附件、发送/停 | 提交这一条 → Composer |
| **工具预设** | 会话/工作区「代理能用多少工具」的权限，像 IDE 模式 → 底栏；点击出列表 |
| **喇叭** | 应用级完成音偏好，与当前输入无关 → 底栏（用户已拍） |

禁止第三份：设置页再抄一套工具预设；Composer 菜单再抄 Options。

**实现事实（已更新）**：`AppStatusBar` 右簇已挂压缩 / 工具 / 喇叭。Composer 铬条不再含这三项。R-13 后续不得回改 `ChatInput`。

## 1. 产品原则

1. **Composer 一块边框**：模型×思考、压缩、圆环、附件、发送/停止都在圆角框内。
2. **主按钮是态机**：发送与停止同一圆、同一热区。
3. **箭头向上**：内容送进上方对话流。
4. **先藏诊断、后藏压缩、永不藏发送**；底栏项不随对话列变窄消失。
5. **不假装 Cursor 没有的模式**：无假 Agent；不把 default 叫 Fast。
6. **一层一个职责**：权限与提示音不进输入框。

## 2. 目标布局

```text
┌─ Composer 边框 ──────────────────────────────────────────┐
│  textarea / 行内技能高亮                                  │
│                                                           │
│  [思考摘要 ▾]  [压缩]            [圆环?] [夹子] [↑ / ■]   │
│   └ Effort + Model >                                      │
└──────────────────────────────────────────────────────────┘

窗口底栏右簇（R-13，22px 密度）
  …  [扳手 default ▾]  [喇叭]  [Token?]
         └ 向上：off / read-only / default / full
```

- **左簇**：思考摘要为主触发（如 `high`）；菜单只分 **Effort** 与 **Model >**。完整模型名不长期铺开。
- **压缩**：框内独立按钮，灯泡/思考组右侧。宽时「图标+压缩」；窄时先去字留图标。进行中用 **自己的** 小方块，不占发送圆钮。
- **右簇**：圆环（可藏）→ 附件 → 主按钮。语音灰钮仍先藏。
- **框外 Bottom bar 删除**。
- **组合菜单不再含工具 Options**（已拍迁底栏）。比第一版更接近 Cursor 的 Effort + Model。

### 2.1 压缩怎么「设计进来」（独有能力，不抄 Cursor）

压缩没有 Cursor 对标件，按 **会话动作** 而不是 **窗口偏好**：

| 态 | 外观 | 行为 |
|----|------|------|
| 空闲 | 对向箭头图标 + 可选「压缩」 | `onCompact` |
| 进行中 | 小方块 +「压缩中」 | `onAbortCompaction` |
| 流式生成 | 保留、禁用（半透明） | 避免与主钮停止抢点击 |
| 刚结束 | 框 **上方** 仍可用现有结果/错误条 | 不另起 Toast 气泡 |

窄列卸压缩后：`/compact` 仍可用。**已拍：直接隐藏，不加「⋯」。**

## 3. 主按钮态机（PR-02 / PR-06）

| 状态 | 图标 | 底色 | 动作 |
|------|------|------|------|
| 空闲且无正文/无图 | **向上**箭头 | 弱底、禁用 | 无 |
| 空闲且可发 | **向上**箭头 | `--accent` | `handleSend` |
| `isStreaming` | **圆角小方块** | 中性或轻警告，不要整条红框 | `onAbort` |
| 压缩中 | 主按钮不变 | — | 压缩钮自己的方块 |

删除框外 `Stop` 文案按钮。

**已拍选项 A（跟 Cursor）**：生成中主钮只做停止，左侧 **不** 画打断/排队。含义见 [10-决策记录 §2](./10-决策记录_20260819_Composer铬条Gate.md)。底层 steer/follow-up 能力本期不砍，只去掉铬条上那两颗钮。

## 4. 收窄策略（仅 Composer 框内）

`ResizeObserver` 按优先级 **卸载**，禁止切半个按钮。

1. 上下文圆环  
2. 语音占位  
3. 压缩：文案 → 图标 → 卸载  
4. 左簇：截断 → 只留图标  
5. 保留：附件、主按钮  

喇叭、工具预设 **不在此顺序**（底栏全宽，自己按 R-13 D6 收窄：先留图标）。

圆环藏掉后，用量仍可走 R-13 D5 Token。不要两处同时常显圆环+Token 抢同一信息（D5 若拍 A，Composer 圆环更应先藏）。

## 6. UX / PM 审查（修订后再审一遍）

### 6.1 分层是否站得住

| 判断 | 结论 |
|------|------|
| 喇叭进底栏 | **对**。完成音是窗口偏好，Cursor Composer 截图也没有喇叭。 |
| 工具预设进底栏 | **对，且比塞进 Medium Fast 菜单更诚实。** default 不是 Fast；放底栏等于承认「这是本仓的代理权限」，用户点底栏出列表，可发现性不降。 |
| 压缩留 Composer | **对。** 压缩的对象是 **当前对话上下文**，和圆环同一问题；放底栏会变成「全局格式化」错觉。 |
| 模型不进底栏 | **仍对**（D1）。换模型是写提示的一部分。 |

### 6.2 风险

| 风险 | 处理 |
|------|------|
| 底栏 22px 里「default」比 Composer 32px 胶囊弱 | 用扳手+短名；hover 抬亮；菜单内容与现在四档一致，不缩成纯图标一期（除非 D6 窄屏） |
| WP-C 先于 WP-S1 | 工具入口会空窗 → 硬依赖 |
| 流式时底栏仍能改工具 | 与现逻辑对齐：**禁用**，勿隐藏（PR-07） |
| 无会话也显示 default | 无会话禁用或隐藏工具项；喇叭可留 |
| 压缩常显占窄列 | 按 §4 卸；圆环更先卸 |
| Token + 圆环双显 | R-13 D5-A 时 Composer 圆环作为可藏诊断件，不抢底栏用量 |

### 6.3 与 Cursor 的诚实差距

| Cursor | 我们 |
|--------|------|
| Agent 胶囊 | 无，不假造 |
| Medium Fast = Effort+Fast | 我们：思考摘要 + Model；Fast 不存在 |
| 底栏无工具预设 | 我们底栏有：本仓能力，不假装是 Cursor 标配 |
| 无压缩 | 我们框内有压缩：独有，单独设计 |

### 6.4 回归红线

- 路线 C 技能高亮、IME、Enter 发送。
- `onAbort` / `onCompact` / `onToolPresetChange` / `useAudio` 契约不改，只改挂载点。
- 底栏菜单向上，不被系统任务栏挡住（R-13 已写）。
