## 1. 改了什么

| 项 | 原状 | 现况 |
|----|------|------|
| 语音圆圈 | 灰钮占位，「尚未接线」 | **去掉**。没有能力就不画 |
| 停止方块 | 曾做成反相黑底 + 12×12 大白块 | **Cursor 比例**：浅底圆（`text` 14% 混底）+ 约 8×8 前景圆角方 |
| 圆环 | 无 `contextWindow` 或列宽 &lt; 400 就不画 | 有对话列就画；无数据按 0 /「未知」；仅 &lt; 220px 卸掉 |
| 铬条密度 | 28px 热区、12px 字、框垫 10/12 | 22px 热区、11px 字、框垫 8/10/4，行距更紧 |
| 压缩 | 框内左簇 | **迁窗口底栏**（R-13 D9），Composer 不再画 |

## 2. 停止钮设计依据

对照用户截图（左 Cursor / 右本仓）：Cursor 是**浅灰圆 + 中等实心方**，方块约占圆直径四成，和夹子同一量级。反相黑底加大白块会压过整排铬条。现圆 22、方约 7.7、`rx=1.55`，浅底不描边。
