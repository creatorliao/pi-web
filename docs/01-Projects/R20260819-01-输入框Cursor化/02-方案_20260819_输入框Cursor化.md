# 方案：输入框 Cursor 化

| 属性 | 值 |
|------|----|
| 日期 | 2026-08-19 |
| R 主题 | R20260819-01-输入框Cursor化 |

## 1. 对照 Cursor（用户本次定义）

```text
任意位置 /  →  列表  →  就地插入 /skill:foo 
                ↓
    「先 /skill:foo 再检查类型」   ← 后接指令
    「/skill:a 然后 /skill:b」     ← 多颗
    画面上 /skill:foo 只变色一次   ← 一份提示
```

当前缺口：`slashQuery` 写成 `value.startsWith("/") && 整段无空格`，且 `applySlashCommand` 执行 `nextValue = \`/${command.name} \``，**整框覆盖**。这直接违反 F-03b/c/e。

## 2. 路线比选（最贴近 Cursor 且贴本仓库）

| 路线 | 做法 | 贴近 Cursor | 对本仓库 | 结论 |
|------|------|-------------|----------|------|
| A 行内 DOM 节点 | contenteditable / Tiptap chip | 最高（真节点） | 中文 IME、草稿、现有 Enter/@ 全要重做 | **过度**；用户要的是「变色 + 后接字」，不是独立 AST |
| B 可见 textarea 上色 | 无法给同一框里的一段字上色 | 低 | IME 最稳 | **达不到** F-03 |
| **C 单层叠字** | 保留 textarea 真源；**去掉芯片条**；叠加层与字框 **完全重合** 只负责上色；插入改「当前 /token」 | 高：一份字、就地变色、后面接着打、任意 `/`、多颗 | 复用 IME、draft、`/` `@` 菜单 | **采用** |

C 和上一轮「透明字」的差别不在「叠不叠」，而在：

1. **禁止**顶栏再抄一颗芯片（那是第二份）。
2. 叠加层与 textarea **同字体、同折行、同 padding**，选区用 CSS 压掉蓝底幽灵（`textarea::selection { color: transparent; background: transparent }`），caret 留在真源上，人眼只看到叠加层那一份着色字。
3. **禁止** `applySlashCommand` 清空全文。

这样「光标在底部透明技能里」不再成立：底下没有第二份可见 token，也没有顶上一份。

## 3. 施工设计（路线 C）

### 3.1 触发（F-03c）

新增 `extractSlashQuery(textBeforeCursor)`，规则对齐 `@`：

- `/` 在行首，或前面是空白 / 换行；
- 查询为 `/` 后到光标、且查询内无空白（打空格即闭合，菜单关）；
- `foo/bar` 不触发。

`slashQuery === null` 的旧整框判断删除。

### 3.2 插入（F-03b/d/e）

`applySlashCommand`：

```text
before = value.slice(0, token.start)
after  = value.slice(caret)          // 保留后文
insert = `/${command.name} `         // 后留一空格给指令
next   = before + insert + after
caret  = before.length + insert.length
```

同步 `valueRef`；短时吞 Enter 连发；高度走 `applyComposerFieldHeight`。

### 3.3 一份显示（F-03/F-03a）

- 删除 `closedComposerTokens` 芯片条。
- 保留 `ComposerHighlight`：技能 `border-radius: 999px` + `box-shadow` 扩边（不占字宽）；`word-break: keep-all`。
- textarea 字透明、caret 可见；`::selection` 透明，避免蓝底第三份。
- 技能一种色（`--accent`），`@` 用 `--user-bg`，其它 `/` 用 muted。

### 3.4 圆环（F-10）

`ContextUsageRing` 自绘 hover 卡：百分比 + `tokens / contextWindow`。不用原生 `title`。

### 3.5 其它已落地且保留

拖高、图标发送、N Files 顶栏、Review/Undo/Voice 灰按钮。

## 4. 未接线 / 明确不做

同前：Review、Undo、Voice、无数据源的 `@` 类型；发送仍是纯文本。
