## 目标（Why + What）

- **业务目标**：窗口有全宽底栏，与系统任务栏分开。
- **用户价值**：IDE 壳（Git / 对话分支）跟 VS Code / Cursor 底栏一致；写提示仍用已经做完的 Composer。
- **分层（勿混）**：
  1. **窗口壳** → Git / 项目 / 对话分支（左簇，待做）。
  2. **Composer** → 已完善，**本专题零改动**。
  3. **底栏右簇** → 压缩 / 工具预设 / 喇叭（已落地，维持）。
- **成功标准**：
  1. 任意主视图最底有独立底栏。
  2. Composer 铬条与冻结基线一致（模型×思考、圆环、附件、发送/停）。
  3. 底栏没有模型名、思考档、发送；右簇有压缩、工具、喇叭。
  4. 对话分支、Git 进左簇（D2/D3 确认后）。

## 非目标（Out of Scope）

- **禁止**再改 `ChatInput` / `composer-chrome` / `composer-tokens`（含删未用 props、改密度、改菜单）。
- **禁止**把压缩 / 工具 / 喇叭画回 Composer。
- 不做完整 SCM、Problems、扩展贡献点。
- 不重做三栏、对话标题、历史分组（R-03）；只迁顶栏对话分支入口。
- 不把 `FileViewer` 细条升成第二条窗口底栏。
- 不把 `ExtensionStatusBar` 并进窗口底栏。

## 约束

- 余下施工可以改 `AppStatusBar` / `AppShell` 底栏接线 / `BranchNavigator` 变体，**不可以**改 Composer 文件。
- Git vs 对话分支分名分图标。
- Toast 规范不变。
