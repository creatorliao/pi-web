## 1. 产品判断

缺的是 **应用自己的地面**。Composer（R-01）已经按 Cursor 输入区做完，**本专题不再碰它**。

| 层 | 放什么 | 本仓 |
|----|--------|------|
| **IDE 壳** | 底栏 Git / 项目；顶栏页签 | 左簇待做：Git、项目、对话分支 |
| **Composer** | 模型 × 思考、圆环、附件、发送/停 | **冻结**，见 §2.3 |
| **底栏右簇** | 压缩、工具预设、喇叭 | **已落地**，只维持，不回迁 |

原则：

1. **一条全宽地面**（`app-statusbar`）。
2. **左簇「我在哪」**；右簇已是会话动作 / 权限 / 提示音。
3. **Composer 零改动**：不迁入、不迁出、不抽公共、不删死 props。
4. **两种分支分名**：Git vs 对话分支。
5. **空态走 Toast**。
