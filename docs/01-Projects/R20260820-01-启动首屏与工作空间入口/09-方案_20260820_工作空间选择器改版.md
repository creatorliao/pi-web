## 1. 目标与非目标

**做完之后**

```text
左栏第一行：当前项目名（文件夹标）→ 点开切换器
产品表面不出现 worktree 概念（小白）
选择器：星标置顶 · 默认最近使用 · 可隐藏 · 可重置隐藏
打开本机目录 / 今日目录：标题行右侧
欢迎页与模态同一套，只是壳不同
```

**做**

- 左栏入口去「下拉脸」
- 侧栏 **去掉全部 worktree 控件**（下拉 / 新建 / 删除 / 引导条）；文案不出现「worktree」
- 选择器顶栏：打开目录 / 今日目录（模态另保留关闭）
- 星标、隐藏、重置隐藏
- 默认排序：星标组优先，组内按最近会话时间
- 视觉：小圆角、少描边戏、当前态用左侧指示而不是蓝胶囊

**不做**

- 欢迎页「下次自动进入」
- 卡片上预拉 Git / 缩略图 / 教练箭头
- 第二套「收藏夹」并列列表（星标只是同一网格里置顶）
- 删除会话文件或磁盘目录
- 面向小白讲解或操作 worktree（含侧栏管理）；底栏 Git 分支名是 R-13 已有地面，本轮不扩、不在入口复述
- 改 Composer、R-02 字族

## 2. 信息架构

```text
换「项目 / 目录」 → 欢迎页或左栏入口 → WorkspacePicker
换「对话树分支」 → 底栏对话分支（已有）
```

选择器与左栏入口不出现 Git / worktree。内核仍按项目根归并会话（人看不见「工作树」这个词）。

## 3. 左栏入口（初始化感，不像下拉）

**现在**：满宽浅底圆角条 + 名字 + **∨**。

**改为**（对齐 VS Code 窗口标题 / JetBrains 当前项目）：

```text
[文件夹]  prompts-extract-master
```

| 规则 | 规格 |
|------|------|
| 形状 | 无描边或仅底部分割线；**不要**满宽胶囊、不要下箭头 |
| 图标 | 16px 文件夹（线性、当前色 `--text-muted`），声明「这是目录」 |
| 文字 | 项目名，13px、字重 600，单行省略；完整路径只进 `title` |
| 交互 | 整行可点，打开同一套 Picker 模态；`aria-haspopup="dialog"`，不要 `aria-expanded` 装成 combobox |
| 悬停 | 仅背景 `--bg-hover`，可加右侧极淡「切换」二字（12px、`--text-dim`），默认不常驻 |
| 其它工作区有未读 | 保留小圆点，仍靠右 |

欢迎页没有这一块（仍是全屏选卡）。进入之后，左栏第一眼应是「我在这个项目里」，而不是「这里有一个未展开的 Select」。

## 4. 不向小白暴露 worktree（Gate-S）

**拍板：产品表面不出现 worktree 概念。** 小白只理解「打开一个文件夹开始对话」。

| 层 | 做 |
|----|----|
| 欢迎页 / 切换模态 | 不画分支、不写 worktree |
| 左栏 | 只留文件夹 + 项目名；**整块移除**下拉、新建、删除、灰色引导条 |
| 底栏 Git | 本轮不改 R-13（分支名是 IDE 常识，不是本夹要教的词） |
| 内核 | 继续按 `projectRoot` 归并会话；人不用知道这叫 worktree |

## 5. 选择器壳与顶栏

一套组件，两种宿主。

### 5.1 欢迎页（初始化）

```text
Pi Web                                              打开本机目录…    使用今日目录

选择工作空间
打开一个目录后再开始对话

[ 搜索：仅项目 > 8 才出现，直角输入，不要胶囊 ]

  ★ 常用…          其余按最近…
  +--------+  +--------+  +--------+
  | 名称   |  |        |  |        |
  +--------+  +--------+  +--------+
```

- 产品名仍 13px、`--text-dim`，不做成 Logo 墙。
- 两个打开动作在**第一行右侧**，文字按钮，字重与标题分开：它们是「没有卡片时的出路」，不是页脚附录。
- 网格仍垂直居中，上下留白大于装饰。空列表：副题 + 右上角两个动作即可，不画空卡。

### 5.2 切换模态

```text
切换工作空间              打开本机目录…    使用今日目录    ×

[ 搜索 同上 ]

卡片网格…
```

- 面板：最大宽 880px；圆角 **6px**；1px `--border`；阴影只够和遮罩分层（`0 8px 24px` 量级，不要大模糊光晕）。
- 关闭仍在最右；Esc 不换 cwd。
- 「当前」卡可再点一次仅关模态（保持 04）。

两个文字按钮样式：无底、无圆角胶囊、`--text` / 悬停 `--accent` 或底划线。不要主色大块 CTA。

## 6. 卡片（干净、专业）

保持每行最多 3 张、间距 12px、不足 3 张左对齐。改的是**密度和圆角**，不是再发明一种卡。

| 元素 | 规格 |
|------|------|
| 外框 | 圆角 **4px**；1px `--border`；默认无投影 |
| 内边距 | 12px 14px |
| 悬停 | `--bg-hover`，边框略加深；星标 / 隐藏才显现 |
| 当前 | **左侧 2px `--accent` 条** + 名称不改色即可；去掉蓝描边满框和「当前」胶囊（需要的话用 11px `--text-dim`「当前」跟在名称后，不要色块） |
| 标题 | 目录最后一段，15px、字重 600、单行省略 |
| 路径 | 12px 等宽、`--text-muted` |
| 脚 | 相对时间 · 会话数（或「尚无对话」），12px `--text-dim` |
| 星标 | 右上，默认隐藏；已星标始终显示实心星。点星 **不进入项目**（`stopPropagation`） |
| 隐藏 | 星标旁 ×；仅悬停出现。点 × **不进入项目** |

搜索框：高 32px，圆角 **4px**，不要 pill。

占位加载：三块矩形，圆角同样 4px，不要圆角砖。

## 7. 星标 · 排序 · 隐藏 · 重置

### 7.1 数据（可追溯 · 落在 pi 配置空间）

调查见 [10-调查](./10-调查_20260820_pi配置空间与web持久化.md)。**不写 localStorage，不写 `settings.json`。**

| 项 | 规格 |
|----|------|
| 路径 | `{getAgentDir()}/web.json`（默认 `~/.pi/agent/web.json`；`PI_CODING_AGENT_DIR` 时跟会话同一棵树） |
| 角色 | Pi Web **壳配置**（TUI 不读）。以后同类「跟人走、跟这台机的 agent 目录走」的数据加**顶层段**，不另起文件，除非单文件明显过大 |
| 写盘 | 服务端读-改-写 + 原子替换（复用现有原子写习惯）；**保留未识别的顶层键**，禁止客户端 PUT 整文件 |
| 身份 | `key` = 现有 `workspaceKeyOf` / `WorkspaceCard.key`；worktree 仍并进同一项目 |

图式（`version` 必有；本轮只填 `workspaces`）：

```json
{
  "version": 1,
  "workspaces": {
    "starred": [
      { "key": "<workspaceKey>", "at": "2026-08-20T05:00:00.000Z" }
    ],
    "hidden": [
      { "key": "<workspaceKey>", "at": "2026-08-20T05:01:00.000Z" }
    ]
  }
}
```

- `starred` / `hidden` 用对象数组而不是纯字符串，便于以后加备注、来源；本轮只认 `key`，`at` 作审计。
- **组内排序仍按会话 `lastModified`**，不按 `at`（Gate-S：待确认-3 = A）。
- 读失败或文件不存在 = 空 `workspaces`，不打断欢迎页。JSON 损坏不覆盖原文件。
- 以后可加、**本轮不写**的顶层段（占位，防止后人再开平行文件）：`lastOpenByWorkspace`（今天仍在 localStorage）、其它壳偏好。主题/栏宽/音效继续留浏览器。

HTTP（施工名可微调，语义不能少）：`GET` / `PATCH /api/web-config`。欢迎页与模态共用这一份，浏览器不另存真相。

### 7.2 默认顺序（推荐：不做排序条）

```text
1. starred ∩ 未隐藏：按 lastModified 新→旧
2. 其余未隐藏：按 lastModified 新→旧   ← 已是 getRecentProjects()
```

没有「项目创建时间」。会话 `modified` 就是人能理解的「最近用过」。再做创建时间会骗人。

排序按钮：**不做**（Gate-S：待确认-1 = A）。人要的「最近在前」已经是默认。

### 7.3 星标

- 点空星 → `PATCH` 把该项推进 `workspaces.starred`，卡跳到网格前部。
- 再点 → 从 `starred` 去掉，落回最近组。
- 欢迎页与模态读同一份 `web.json`。

### 7.4 隐藏（关闭）

- × = **从选择器消失**，不是删项目、不是删对话。
- 当前正在使用的项目：仍可隐藏（列表里没了，cwd 不变）；下次打开选择器不再出现。
- 用「打开本机目录」再次选中同一路径：**自动从 hidden 去掉**（人明确要回来）。
- 不二次确认（能重置）。Toast 一句：「已从列表隐藏」（可撤销下一句不强制；重置是正式恢复口）。

### 7.5 重置

- 文案：「恢复隐藏的项目」。
- 出现条件：`workspaces.hidden` 非空才显示，放在顶栏两个打开动作左侧或搜索行最右，**文字链**，不要常驻齿轮。
- 只清空 `hidden`。**不清 `starred`**（点错隐藏 ≠ 要打散常用）。
- Toast：「已恢复 N 个项目」。

无隐藏项时不占位（没有内容就不要打开一层）。

### 7.6 磁盘上已不存在的目录（F-12 / F-13）

**人看到的：** 选择器里没有「幽灵文件夹」。以前用过、现在资源管理器里已经没了，卡片就不画。

**怎么滤：**

```text
GET /api/sessions 给每条会话标 directoryExists（按 projectRoot ?? cwd 做一次 stat，同路径缓存）
getRecentProjects / toWorkspaceCards：directoryExists === false 的项目不进网格
```

| 规则 | 做 | 不做 |
|------|----|------|
| 判断 | 服务端 `stat`：路径是目录才算存在 | 浏览器猜、不扫整盘 |
| 会话文件 | 保留 `.jsonl` | 不因缺目录去删历史 |
| 星标 / 隐藏 | `web.json` 可留着旧 key；没有卡就不展示 | 不自动清配置 |
| 点卡 | 仍先 `cwd/validate`；失败 Toast（F-13），不 throw | 不进半残 cwd、不红屏 |

目录后来又建回来：下次拉会话列表会重新出现（同一 `workspaceKey`）。

## §决策记录

| 项 | 决策 | 理由 |
|----|------|------|
| 打开目录位置 | 标题行右侧 | 进阶主路径应在扫视第一行，不被网格和输入法挡住 |
| 默认序 | 星标（组内最近）→ 最近 | 数据只有会话时间；创建时间不存在 |
| 隐藏语义 | 只改选择器可见性 | 完整：对话还在；不加戏：不弹删库确认 |
| 重置范围 | 只恢复隐藏 | 点错 × 是隐藏场景，不应打散星标 |
| 星标/隐藏存哪 | `{getAgentDir()}/web.json` | 跟人/跟 agent 目录走；TUI 不读；扩展靠加顶层段。否决 localStorage 与 settings.json（见 10） |
| 当前态 | 左 2px 条，去蓝胶囊 | 少一块「生成式」角标 |
| 圆角 | 面板 6 / 卡 4 / 搜索 4 | 对齐 IDE，去掉 10–12 的营销圆 |
| 左栏入口 | 文件夹 + 名，无 ∨ | 打开 dialog，不是展开 listbox |
| 选择器 / 左栏 Git·worktree | **不出现** | 小白不应看见该概念；内核归并保留 |
| 已删目录 | 选择器过滤（F-12）；点卡先校验（F-13） | 不删会话文件 |
| 排序按钮 | **不做** | Gate-S 待确认-1 = A |
| 星标组内序 | 仍按最近使用 | Gate-S 待确认-3 = A |
