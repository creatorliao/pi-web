## 两条原则（本轮拍板依据）

仓库级条文在根目录 `AGENTS.md`「产品价值观」，细则见 [02-Areas 最佳实践](../../02-Areas/20260820-01-最佳实践_产品价值观_好上手与不加戏.md)。本专题是这两条的起源用例，不另立第二套定义。

| 原则 | 含义 | 用来挡什么 |
|------|------|------------|
| 好上手 | 跟 IDE / 项目管理软件的常见开法走，人不用学新套路 | 自创「记住下次进入」开关、左上角箭头教学、半成品三栏当背景 |
| 完整但不加戏 | 该有的入口都在；多出来的偏好、预加载、第二套列表一律不做 | Git 进欢迎卡、营销闪屏、欢迎页再做一遍设置向导 |

对照物：JetBrains 欢迎页（先选项目）、VS Code / Cursor 的 Open Recent 与窗口标题只显示文件夹名。不对照营销落地页。

## 决策一览（原先待确认项全部落定）

| 编号 | 题目 | 落定点 | 依据 |
|------|------|--------|------|
| D1 | 冷启动是否自动进最近项目 | **不自动进。** 先欢迎页选一张卡或选目录。`?session=` / 已校验 `?cwd=` 仍直达 | 好上手：项目型工具的欢迎页。完整：深链不丢。你明确不想被塞进默认目录 |
| D2 | 「下次直接进入」勾选项 | **不做。** 删 F-10 | 不加戏。下次点同一张卡即可，不必多一个会忘的偏好 |
| D3 | 闸门形态 | **一套组件、两种宿主**：冷启动 = 全屏欢迎（背后不画三栏）；已进入后切换 = 居中模态 | 好上手：欢迎页 + 切换对话框。完整：运行中也能换。避免模态罩在半成品壳上再露底 |
| D4 | 启动骨架 | **欢迎页自己当壳。** `boot` 时同一页，卡片位显示「正在加载…」，不画假三栏、不转孤立圈、不当闪屏 | 不加戏。假栏位不能点，只会露底 |
| D5 | 左栏主按钮 | **只显示项目名** + chevron；完整路径进 tooltip 与底栏 / 文件细栏 | 好上手：VS Code 窗口标题也是文件夹名 |
| D6 | 卡片上预拉 Git | **不拉。** 进工作区后再走现有底栏 / worktree | 不加戏，欢迎页少一次等待 |
| D7 | 误出的「开始使用 / 加模型」 | **删除对话列左上角箭头清单。** 仅当模型列表确认空、且人还在欢迎页时，页脚一行「去设置添加模型」 | 完整：真零配置仍有路。不加戏：已配置不教学 |

施工包相应收束：原 P4（记住进入）取消；原 P1+P2 合并为 **WP-A**（否则只关门无入口），原 P3 为 **WP-B**。步骤与验收见 05。

## 设计规格（大方、整齐、少装饰）

气质：留白够、字少、对齐、没有箭头教练、没有重阴影。浅色/深色都只用现有 `--bg` / `--bg-panel` / `--border` / `--text*`。

### 冷启动 · 全屏欢迎

```text
                         Pi Web

                    选择工作空间
              打开一个目录后再开始对话

        +-------------+  +-------------+  +-------------+
        | 名称        |  | 名称        |  | 名称        |
        | 缩短路径    |  | 缩短路径    |  | 缩短路径    |
        | 昨天 · 3 个对话 |  | 3 月前     |  | 尚无对话    |
        +-------------+  +-------------+  +-------------+

              打开本机目录…          使用今日目录
```

| 元素 | 规格 |
|------|------|
| 版心 | 水平居中，最大宽约 880px；卡片区垂直也居中，上下留白大于左右装饰 |
| 产品名 | 13px、`--text-dim`，不做成 Logo 墙 |
| 标题 | 「选择工作空间」，20–22px、`--font-ui`、字重 600 |
| 副题 | 一句；`--text-muted`、13px。不写步骤 1、2 |
| 卡片网格 | 每行最多 3 张；间距 12px；不足 3 张左对齐，不拉巨卡 |
| 一张卡 | 内边距 14–16px；圆角 10px；1px `--border`；默认无投影。悬停：`--bg-hover`，边框略加强。不写图标森林 |
| 卡标题 | 目录最后一段，`--font-ui` 15px，单行省略 |
| 卡副行 | 缩短路径，12px、`--text-muted`（可用等宽，但不小于 12） |
| 卡脚 | 相对时间 · 会话数，12px、`--text-dim`。没有会话写「尚无对话」 |
| 次要操作 | 网格下方两个文字按钮，并列、同等权重，不要主色大块 CTA |
| 搜索 | 项目 **多于 8 个** 才出现在标题下；平时不占一行 |
| 空列表 | 不画空卡片；只留副题 + 两个次要操作 |
| 加载 | 标题先出；网格位三张浅色占位块（无文字），或一行「正在加载最近项目…」 |
| 失败 | 一句错误 + 「重试」；不落到「去加模型」 |

欢迎页**不画**左栏、文件列、对话列、路径胶囊、底栏 Git。窗底色与进入后一致，避免白闪。

### 已进入 · 切换工作空间（模态）

同一网格、同一张卡、同一对次要按钮。差异只有壳：

| | 欢迎页 | 切换模态 |
|--|--------|----------|
| 背景 | 全屏 `--bg` | 半透明遮罩 + 居中面板 `--bg-panel` |
| 标题 | 选择工作空间 | 切换工作空间 |
| 关闭 | 无（必须选一个才能进） | 关闭按钮与 Esc，cwd 不变 |
| 当前项 | — | 对应卡右上角「当前」，点击仍可关模态 |

面板：最大宽约 880px，圆角 12px，1px 边框，一层很轻的阴影（能抬起来即可）。不要第二套列表样式。

### 进入之后（主界面只动入口，不动三栏）

- 左栏第一行：项目名按钮，点击开切换模态。去掉「整段路径当按钮脸」。
- 进入某项目后，仍按现有规则恢复该项目上次会话（R-07）；**没有**则空对话，文案只保留「从历史打开或新建」，不教学加模型。
- 点会话改 cwd、worktree、并行会话：不改。

### 明确不做（本轮）

- 欢迎页勾选「下次自动进入」
- 欢迎卡上的 Git 分支、dirty 点、缩略图
- 对话列「开始使用」箭头教练
- 启动假三栏骨架、品牌闪屏
- 新做一套「最近项目」排序（继续 `getRecentProjects()`）
- 改 Composer、底栏槽位、历史分组
