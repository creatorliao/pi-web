---

## 1. 人要办的事

打开工具或工作中途：**认出当前项目 → 换到要用的目录 → 把常用的留在眼前、把不再关心的拿掉**。失败时能恢复。不要在同一块区域里再学一套「分支下拉」。

## 2. 问题清单（PR）

| 编号 | 现象 | 根因 | 伤害 |
|------|------|------|------|
| PR-01 | 左栏第一块是圆角条 + 项目名 + **向下箭头**，读起来像下拉框，不像「打开切换工作空间」 | 04 D5 明确写了「项目名 + chevron」；实现是满宽胶囊底 + `polyline` 下箭头（`SessionSidebar` 约 988–1038 行） | 人以为要点开选分支或选最近项的窄菜单，和已经改掉的旧下拉混淆 |
| PR-02 | 左栏项目名正下方还有 **worktree / 主分支** 下拉（分支图标 + `main` + 下箭头） | R-13 已把 Git / worktree 放进底栏左簇；侧栏旧切换器没撤 | 同一件事两个入口；和「换工作空间」叠在一起，入口区像初始化失败、控件堆砌 |
| PR-03 | 「打开本机目录…」「使用今日目录」贴在**卡片网格下方左侧** | 04 规格：次要操作在网格下、同等文字链 | 打开新目录是进阶主路径，却落在视口底；模态里还容易被输入法条挡住 |
| PR-04 | 卡片不能固定常用项；也不能把不再关心的项目从选择器拿掉 | 04 明确不做「第二套排序」；列表 = `getRecentProjects()` 全量 | 会话一多，常用目录被挤走；误关无恢复 |
| PR-05 | 用户希望按时间 / 最近使用排序，并有排序控件 | 数据上**已经按最近会话时间倒序**；没有「项目创建时间」字段；也没有排序条 | 人以为没排序；若再加创建时间，对不上真实数据 |
| PR-06 | 模态 / 搜索 / 卡片圆角大、搜索条偏胶囊、「当前」用蓝色角标 | 04 写了卡片 10px、面板 12px；实现搜索 `borderRadius: 8`，当前项 accent 描边 + 文案「当前」 | 像生成式 UI 模板，不像 IDE 欢迎/切换；入口应给「可以开始干活」的静，而不是产品发布页 |
| PR-07 | 欢迎页与模态共用组件，改一处会一起变 | 刻意一套 UI（D3） | 不是缺陷；改版必须两宿主一起收，欢迎页仍要像**初始化选项目**，不能做成设置中心 |

## 3. 对照物（好上手）

| 产品 | 换项目怎么做 | 常用 / 去掉 | 气质 |
|------|--------------|-------------|------|
| JetBrains 欢迎页 | 左侧**最近项目列表**（不是大圆角营销卡）；顶栏/侧栏「Open / New」 | **星标置顶**；右键或 × **从最近移除**（不删磁盘） | 小圆角或直角行、字密、少阴影 |
| VS Code / Cursor | Open Recent；欢迎页左侧最近列表 + 文字链 Open Folder | 可从最近移除；窗口标题只显示文件夹名 | 列表 + 文字链，几乎不画卡 |
| 本仓底栏（R-13） | Git 点开切 worktree | 不管项目列表 | 地面控件，不占左栏第一屏 |

本仓已拍板「卡片网格、一套两宿主」，对照的是 **JetBrains / VS Code 的职责和密度**，不是改成落地页三列大卡。

## 4. 非问题（避免扩 scope）

- 冷启动先选卡、不自动进最近项（D1）——保持。
- 深链 `?session=` / `?cwd=` ——保持。
- 隐藏卡片 **不等于** 删 `~/.pi/agent/sessions` 里的对话，也不删磁盘目录。
- 对话树分支（Continue / BranchNavigator）与 Git 分支不是一回事；本报告不改对话分支。
- 字族与抗锯齿仍归 R-02。
