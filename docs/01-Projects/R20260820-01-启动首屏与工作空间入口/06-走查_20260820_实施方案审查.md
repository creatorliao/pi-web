## 问题报告（摘要）

### PR-01 进入后写 `?cwd=` 会废掉 D1/D2

- **现象**：05 没规定进入后的 URL。现码在选会话时会 `replace(?session=)`。若施工「为了完整」顺手写上 `?cwd=`，下次打开带 query，欢迎闸门被跳过。
- **根因**：深链 `?cwd=`（F-09，人明确带了路径）和「进入后留下 cwd」（产品自己记住）不是同一件事。
- **对照**：VS Code / JetBrains 打开文件夹后刷新不会靠 URL 记住；D2 已否决「下次直接进入」。
- **方案**：只维持会话深链。自定义目录成功也不写 `?cwd=`。

### PR-02 多画一屏 / 两套相位

- **现象**：05 有 `entering`「保持欢迎壳」；AppShell 已有 `initialCwdStatus`。
- **根因**：露底来自「自动选 cwd 后路径先于架子」。人已经点了卡，cwd 已知，直接挂三栏，路径和架子同帧到，不必再垫一屏。
- **对照**：不加戏——假等待不是完整。

### PR-03 加模型页脚再误伤

- **现象**：`GET /api/models` 不能在无 cwd 时用（已定）。但「models.json 算有模型吗」、auth 看哪个字段、失败时页脚闪一下，没写死。
- **根因**：原 bug 是把「还不知道」画成「第一次用」。
- **方案**：见 05 §4.1 修订。`configured === true` 或 `loggedIn === true` 即为有鉴权。

### PR-04～PR-08

见上表。PR-04 不破坏统一 Toast；PR-05 不在卡上拆 worktree（D6）；PR-06 不发明关项目回欢迎（关窗口才是 IDE 习惯，本产品是单页）。
