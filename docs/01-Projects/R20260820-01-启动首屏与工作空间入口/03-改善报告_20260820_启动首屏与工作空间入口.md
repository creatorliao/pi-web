## 推荐总图

把「打开工具」拆成两段，中间用同一扇门：

```text
冷启动
  ├─ 壳先齐：三栏骨架或全屏闸门（同底色、同窗框，无业务字）
  ├─ 后台拉：会话列表 / 最近项目 / 模型是否可用
  └─ 门闩打开
        ├─ 有 ?session= 或已校验 ?cwd=  → 直接进
        ├─ 用户曾勾「下次直接进入」且记录仍有效 → 直接进
        └─ 其余 → 工作空间卡片闸门（必须点一张卡或选目录）

已在工作区
  └─ 点项目名 / 路径 → 再开同一闸门（模态，不整页重载）
```

引导文案只在门闩之后仍满足「无可用模型」时出现，且放在闸门页脚或设置入口，**不再画在对话列左上角抢第一帧**。

## 1. 首屏稳定性（对应 F-01、F-02、F-11）

**推荐：应用级就绪门闩 + 骨架，不单独做一张营销闪屏。**

| 阶段 | 允许画 | 禁止画 |
|------|--------|--------|
| `boot`（列表/模型未返回） | 窗框、栏位色块、底栏空轨 | 路径字符串、文件名、引导箭头、「开始使用」 |
| `gate`（已返回、尚未进入） | 卡片闸门 | 自动 cwd、自动恢复会话到主区 |
| `ready` | 现有三栏 | — |
| `boot-error` | 完整错误面 + 重试 | 回落到「去加模型」 |

实现要点（确认后才写）：

- `AppShell` 增加显式 `bootStatus`，不要再用 `!activeCwd` 代表「第一次用」。
- `page.tsx` 给 `Suspense` 一个与 `--bg-panel` 同色的壳 fallback，避免白闪。
- 侧栏在 `boot` 期间不执行 `setSelectedCwd(projects[0])`。

**不推荐：** 纯白 Logo 闪屏超过约 300ms——会让工具更像网站。骨架或闸门本身就是品牌。

## 2. 引导不再误出（对应 F-03、F-04）

**推荐：拆成两个独立谓词。**

| 谓词 | 真值来源 | 为真时做什么 |
|------|----------|--------------|
| `modelsReady` | `GET /api/models` 的 `models` / `modelList` 非空，或鉴权后内置供应商已可用 | 闸门不出现「去设置加模型」 |
| `hasWorkspace` | 人已选过卡片，或 URL 已指定 | 关闭闸门，进入主区 |

只有 `modelsReady === false` **且** 人还在闸门里，才显示一步：「打开设置 → 模型」。已配置用户即使启动慢，也看不到这句话。

对话列左上角绝对定位箭头清单：**删除**。空对话列在 `ready` 且已有 cwd、未选会话时，只保留「从历史打开或新建」（现有 `workspace.selectSession` 一类）。

## 3. 工作空间卡片闸门（对应 F-05～F-10）

**推荐：模态选择器，启动与切换共用。**

### 3.1 信息架构

每张卡只回答三件事：这是哪个项目、上次什么时候动过、我能不能马上进去。

```text
┌ 选择工作空间                              ✕ ┐
│  [ 搜索路径或项目名           ]              │
│  ┌────────┐ ┌────────┐ ┌────────┐          │
│  │ 名     │ │ 名     │ │ 名     │   …      │
│  │ ~\code\…│ │ …     │ │ …     │          │
│  │ 昨天   │ │ 3 个会话│ │ git   │          │
│  └────────┘ └────────┘ └────────┘          │
│  [ 打开本机目录… ]  [ 使用今日默认目录 ]     │
│  ☐ 下次打开直接进入上次选择（默认不勾）       │
└─────────────────────────────────────────────┘
```

- 标题用目录最后一段（`prompts-extract-master`），副行用缩短路径。
- 元信息：最近会话时间、该项目会话数；Git 则标分支短名（已有 worktree API 可懒加载，首屏不挡进入）。
- 当前已进入的项目在运行中再次打开闸门时，该卡有「当前」标记。

### 3.2 交互

| 动作 | 结果 |
|------|------|
| 点卡片 | 校验/采用该 root → 关闸门 → 按 R-07 恢复该项目上次会话，没有则新对话空态 |
| 打开本机目录 | 复用现有 `DirectoryPicker` + `POST /api/cwd/validate` |
| 今日默认目录 | 复用 `POST /api/default-cwd` |
| Esc / 启动时无当前工作区 | 启动态不能 Esc 掉进「空默认」；运行中 Esc 关闸门、cwd 不变 |
| 搜索 | 过滤卡片；超过约 8 个项目时输入框默认展开（与现下拉阈值对齐） |

### 3.3 左栏怎么改

左栏顶部不再用「整段路径下拉」当主切换。改为：

- 一行：**项目名**（可加短路径 tooltip）+ chevron，点击开闸门。
- 完整路径留给底栏、文件细栏、卡片副行——启动时不会先甩出一长串盘符。

这同时减轻「路径露底」：启动阶段根本不画那条路径胶囊。

### 3.4 与 R-07 的边界

| 仍属 R-07 / 现状保留 | 本夹接管 |
|----------------------|----------|
| 点会话改 cwd、worktree、并行会话 | 启动是否自动进最近项目 |
| validate / default-cwd / 文件根白名单 | 选择器视觉与门闩 |
| `last-open-by-workspace` 的恢复规则 | 恢复发生在**进入之后**，不发生在门闩前 |
