---

## 1. 结论

星标、隐藏（以及以后同类的「跟这个人、跟这台机上的 pi 走」的数据）**不要**写 `localStorage`，也**不要**塞进 `settings.json`。

落点：

```text
{getAgentDir()}/web.json
```

默认即 `~/.pi/agent/web.json`。若设了 `PI_CODING_AGENT_DIR`，跟会话、models、auth 走同一棵树。

这是 **Pi Web 壳的可扩展配置文件**：TUI 不读；写盘时保留未识别的顶层键，便于以后加段。

---

## 2. `~/.pi/agent` 现在已经有什么

SDK `getAgentDir()`：环境变量（支持 `~`）→ 否则 `{homedir}/.pi/agent`。Web 与 TUI 共用这棵树（见 [领域笔记](../../02-Areas/20260819-01-pi-web与本机pi内核关系.md) §3.4）。

| 路径 | 谁写 | 性质 | 能不能塞星标 |
|------|------|------|----------------|
| `settings.json` | `SettingsManager`（TUI + Web 设默认模型/思考/插件开关） | Agent **运行时**默认值 | **不能。** flush 可能按 schema 重写，未知键不保证活下来；和「列表治理」不是一层 |
| `models.json` | `lib/models-config-store.ts` | 供应商与模型目录 | 领域错；写坏会影响全站选模型 |
| `auth.json` | `AuthStorage` | **密钥** | 禁止混放 |
| `sessions/<encoded-cwd>/*.jsonl` | SessionManager | 单条对话 | 星标是跨会话的项目偏好 |
| `skills/`、`bin/` | 技能与工具 | 资源 | 不是配置 JSON |
| `ProjectTrustStore`（SDK，按 cwd 信任） | 项目扩展是否执行 | 安全决策 | 语义不是「从选择器隐藏」 |
| 仓库内 `.pi/settings.json` | 项目级 | 跟仓库走、可能进 git | 星标是**用户**偏好，不应写进别人 clone 的仓库 |

本仓已有的原子写：`lib/atomic-file.ts` 的 `writePrivateFileAtomicSync`（`models.json` 在用）。新文件复用「先写临时再 rename」，权限按普通配置即可（不是密钥，不必 0o600，但原子替换要保留）。

## 3. 浏览器 localStorage 现在有什么

这些是 **这个浏览器窗口怎么长**，换浏览器或清站点数据就丢，和 `~/.pi` 不是同一份人设：

| 键 | 内容 |
|----|------|
| `pi-theme` | 亮/暗 |
| `pi-sound-enabled` | 完成音 |
| `pi-web:last-open-by-workspace` | 各项目上次打开的会话 id |
| `pi-web:unread-session-ids` | 未读 |
| `pi-web:file-explorer:open` 等 | 栏宽、文件树开合 |
| 工具预设、语言、Composer 高度 | 本机浏览器控件 |

**继续留在 localStorage 的：** 主题、音效、栏宽、语言——离开这台浏览器就没意义。

**不该再放星标/隐藏的原因：** 欢迎页列表已经从本机会话目录来；人换浏览器、换 Chromium 配置、无痕，星标会丢，但对话还在，列表治理就假了。用户明确要求跟 pi 配置空间走。

`last-open-by-workspace` **本轮不迁**（未要求；迁了要处理多页签抢写）。在 `web.json` 里预留顶层键位即可，见 09 图式。

---

## 4. 为什么是一个 `web.json`，而不是 `web/` 目录

| 选项 | 判断 |
|------|------|
| `settings.json` 里加 `web:` | 否，见上 |
| `{agentDir}/web/workspaces.json` | 一个偏好不值得先铺目录；真到三份大文件再拆 |
| `{agentDir}/web.json` | **采用。** 与 `settings.json` / `models.json` / `auth.json` 同级，文件名说明「Web 壳，不是 TUI」 |
| `{agentDir}/pi-web.json` | 更不怕和上游撞名；略冗。若上游将来占用 `web.json` 再改名，靠 `version` + 一次性迁移 |

扩展靠 **JSON 对象加段 + 写盘合并未知键**，不靠一上来拆一堆文件。

## 5. 读写面（施工时）

- 服务端模块（建议名 `lib/web-config-store.ts`）：`readWebConfig` / `patchWebConfig`，路径 `join(getAgentDir(), "web.json")`。
- HTTP：`GET` / `PATCH /api/web-config`（或等价）。PATCH 只提交变更切片，服务端读-改-写，**禁止**客户端 PUT 整文件（以免冲掉未来字段）。
- 欢迎页与切换模态在拉项目列表时一并取 `workspaces`，不要浏览器再存一份真相。
- 文件不存在 = 空配置，不报错。
- 损坏 JSON = 当空，不覆盖原文件（可 Toast）；下次成功写入才替换。
