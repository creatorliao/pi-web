## 1. 目标与非目标（施工边界）

**做完之后人怎么走**

```text
打开 / （无 ?session= / ?cwd=）
  → 全屏欢迎（同 --bg，无三栏）
  → 点卡片 / 打开本机目录 / 使用今日目录
  → 进入三栏；按 R-07 恢复该项目上次会话，没有则空对话

打开 /?session=<id> 或 /?cwd=<已校验路径>
  → 不经过欢迎页，沿用现有直达

已进入后点左栏项目名
  → 同一套卡片，换宿主为居中模态；Esc 关闭，cwd 不变
```

**本夹改**

- 冷启动门闩与欢迎页
- 工作空间选择器（一套组件、两种宿主）
- 左栏入口改为项目名
- 删除对话列「开始使用」箭头清单
- 禁止 `getRecentProjects()[0]` 自动进入

**本夹不改**

- 三栏槽位、Composer、底栏、历史分组、worktree 创建/删除
- 字族 / `next/font` / 抗锯齿（R-02）
- 新 API、第二套最近项目排序、`localStorage`「下次自动进入」
- Toast 体系（失败仍走 `showToast`）

## 2. 状态机（AppShell 唯一真相）

欢迎页未进入时**不挂载** `SessionSidebar` / 文件树 / `ChatWindow` / 底栏，避免侧栏 `useEffect` 再把 `projects[0]` 写进 cwd（见 `SessionSidebar.tsx` 约 718–737 行）。设置弹层仍可挂在 AppShell，欢迎页脚要能打开它。

```text
                    ┌─ 有 ?session= ──► deeplink-session ──► ready（现有恢复）
冷启动 parse URL ──┤
                    ├─ 有 ?cwd= ──► deeplink-cwd（validating / error / ready）
                    └─ 无深链 ──► welcome-loading ──► welcome
                                                      │
                                                      ├─ 拉列表失败 ──► welcome-error（重试回 welcome-loading）
                                                      ├─ 点卡片 / 目录 / 今日目录成功 ──► ready（不另画一屏）
                                                      └─ 真·无模型 ──► 仍停在 welcome，页脚多一行
```

| 相位 | 允许画 | 禁止画 | `enteredCwd` |
|------|--------|--------|----------------|
| `welcome-loading` | 欢迎页标题 + 三张无字占位块或「正在加载最近项目…」 | 三栏、路径、引导箭头 | `null` |
| `welcome` | 卡片网格 + 两个次要按钮；条件页脚 | 同上 | `null` |
| `welcome-error` | 一句错误 + 「重试」 | 「去加模型」（失败 ≠ 零配置） | `null` |
| `deeplink-cwd` validating | 全屏一句「正在打开工作区…」+ 路径 | 三栏 | 校验成功前 `null` |
| `deeplink-cwd` error | 全屏错误 + 路径 + 原因；可回欢迎选别的 | 引导箭头、去加模型 | `null` |
| `ready` | 现有三栏 | 欢迎页 | 非空 |
| `switcher` | `ready` 上叠模态 | 第二套列表 | 不变 |

TypeScript 建议（名称可微调，语义不能少）：

```ts
type WorkspacePhase =
  | "welcome-loading"
  | "welcome"
  | "welcome-error"
  | "deeplink-validating"
  | "deeplink-error"
  | "ready";
```

`switcher` 是 `ready` 上的布尔，不是独立相位。  
`initialCwdStatus` **并入本相位**（validating/error 即上表 deeplink-*），不要两套并存。  
点卡之后可以有内部锁防止连点，**不要**再画一个 `entering` 欢迎壳。

### 2.0 一旦 `ready` 就不回欢迎

换项目只开模态。不提供「关闭项目回欢迎」。回到欢迎 = 用户自己打开没有 query 的 `/`。

### 2.1 进入之后的恢复（不新写规则）

进入某一 `projectKey` 之后，调用现有 `restoreWorkspaceContext`（`AppShell.tsx` / `lib/workspace-memory.ts` 的 `pi-web:last-open-by-workspace`）。没有记忆或会话已删 → 空对话，文案只保留 `workspace.selectSession`（或等价「从历史打开或新建」），**不**画加模型教练。

点卡采用 `getRecentProjects().root`（通常是 `projectRoot`，与现下拉相同）。若上次会话在 worktree，**恢复会话时**再跟到那条会话的 `cwd`，不在卡片上拆 worktree。

点会话改 cwd、worktree、并行会话：不改（R-07）。

### 2.1.1 进入后的 URL（PR-01）

| 动作 | 地址栏 |
|------|--------|
| 点卡 / 打开目录 / 今日目录，尚未恢复到会话 | **保持 `/`，禁止 `replace(?cwd=)`** |
| 恢复或点选了一条会话 | 维持现状：`?session=<id>` |
| 人自己打开 `/?cwd=` | 仍是深链，校验成功则直达（F-09） |

刷新无 query → 欢迎页。若进入后留下 `?cwd=`，刷新会跳过闸门，等于做了已撤销的「记住进入」。

### 2.2 深链失败

| 情况 | 行为 |
|------|------|
| `?session=` 在列表里找不到 | 不回落到 `projects[0]`。进 `welcome`，可另选。现有 `onInitialRestoreDone` 改接到欢迎，而不是占位引导 |
| `?cwd=` 校验失败 | 全屏错误面（现有文案 `workspace.unable`），提供「选择其他工作空间」回到 `welcome` |
| `?cwd=` 与 `?session=` 同时出现 | 维持 `lib/initial-navigation.ts`：有 cwd 则忽略 session |

## 3. 组件契约

### 3.1 `WorkspacePicker`（新文件）

路径：`components/WorkspacePicker.tsx`（样式可用同名 `.module.css` 或 inline + CSS 变量；不要新主题色）。

一套网格，两种宿主由父组件包壳：

| Prop | 类型 | 说明 |
|------|------|------|
| `host` | `"welcome" \| "modal"` | 只影响标题/关闭；网格相同 |
| `projects` | `WorkspaceCard[]` | 已按 `getRecentProjects()` 顺序 |
| `loading` | `boolean` | 占位块，不画假卡片字 |
| `error` | `string \| null` | 非空则网格区只显示错误 + 重试 |
| `currentKey` | `string \| null` | 仅 modal：对应卡标「当前」 |
| `modelsReady` | `boolean \| "unknown"` | `"unknown"` 与 `true` 都不出页脚 |
| `onSelect` | `(project: WorkspaceCard) => void` | 点卡 |
| `onBrowse` | `() => void` | 打开本机目录 |
| `onDefaultCwd` | `() => void` | 今日目录 |
| `onRetry` | `() => void` | 列表失败重试 |
| `onAddModels` | `() => void` | 仅 `modelsReady === false` |
| `onClose` | `() => void` | 仅 modal；欢迎页不传 |

```ts
interface WorkspaceCard {
  key: string;          // workspaceKeyOf / getRecentProjects().key
  root: string;         // 原始路径，进 cwd 用这个
  name: string;         // getFileName(root)
  shortPath: string;    // displayCwd(root, homeDir)
  sessionCount: number; // sessionsForProject(sessions, key).length
  lastModified: string; // 该项目会话 modified 最大值
}
```

卡片展示：

| 行 | 内容 | 字 |
|----|------|----|
| 标题 | `name` 单行省略 | `--font-ui` 15px / 600 |
| 副行 | `shortPath`，左侧省略（抽出 sidebar 的 `PathLabel`） | 12px `--text-muted`；可用 `--font-mono`，**不得小于 12** |
| 脚 | `{相对时间} · {n} 个对话`；`n===0` 时写「尚无对话」（防御；当前列表来自会话，通常 n≥1） | 12px `--text-dim` `--font-ui` |

相对时间复用 `lib/i18n/format.ts` 的 `formatRelativeTime`，**不要**再抄一份 sidebar 里英文 `just now`。

搜索：`projects.length > 8` 才渲染；过滤 `name` / `shortPath` / `root`，大小写不敏感。空匹配：一句「无匹配项目」，仍保留两个次要按钮。

键盘：Tab 在卡片与次要按钮间移动；Enter 激活焦点卡。欢迎页 **不** 响应 Esc。模态：Esc 与关闭按钮 → `onClose`。

视觉数字以 04「设计规格」为准（版心 880、间距 12、圆角 10/12、无重阴影）。

### 3.2 宿主

**欢迎页**（`host="welcome"`）：AppShell 在非 `ready` 时 `return` 全屏层（产品名 + Picker）。`page.tsx` 的 `Suspense` fallback 必须是同色全屏 `--bg`、**不写字**，禁止默认空白。

**模态**（`host="modal"`）：`ready` 下 `switcherOpen`。半透明遮罩 + `--bg-panel` 面板。点当前卡或遮罩/关闭/Esc：只关模态。

### 3.3 左栏入口（WP-B）

`SessionSidebar` 顶部按钮：

- 脸：`getFileName(root)` + chevron，`--font-ui`
- `title` / tooltip：完整路径（现有 `selectedProject?.root ?? selectedCwd`）
- `onClick`：不再 `setDropdownOpen`，改为通知 AppShell `onRequestWorkspaceSwitcher()`
- **删除**窄下拉列表（项目行、筛选、下拉里的「自定义路径 / 默认目录」）。这些能力只活在 Picker
- worktree 切换器、会话树、文件树：不动

`skipInitialProjectSelection`：进入本方案后，**除「深链 session 按目标会话设 cwd」外，永远不再自动选 `projects[0]`**。推荐直接删掉该自动选分支，深链 session 仍走现有 `initialSessionId` 分支。

### 3.4 抽出共享，禁止复制第二套

## 4. 数据怎么取（不新开 API）

欢迎页不挂侧栏，必须自己拉一次列表。

| 数据 | 接口 | 用法 |
|------|------|------|
| 最近项目 | `GET /api/sessions` → `getRecentProjects` | 卡片顺序与现下拉完全一致 |
| 家目录 | `GET /api/home` | `displayCwd` |
| 会话数 / 最近活动 | 同一份 `sessions` + `sessionsForProject` | 卡脚 |
| 模型是否可用 | **不要**在未进入时打 `GET /api/models`（该路由要合法且已放行的 `cwd`，欢迎页没有） | 见下 |

### 4.1 `modelsReady`（避免再误出引导）

只在能**确认没有模型**时显示页脚。请求失败当 `"unknown"`，**不出**「去加模型」（原 bug 就是把「还不知道」画成「第一次用」）。页脚可以晚于卡片出现，**禁止先出再藏**。

```text
1. GET /api/models-config
   任一 providers[id].models[] 里存在非空 id → true（到此为止，不再打 auth）
2. 否则并行：
   GET /api/auth/all-providers   → 任一 configured === true
   GET /api/auth/providers       → 任一 loggedIn === true
   有一个为真 → true
3. 上述请求都成功且都不满足 → false
4. 已有 true 之前发生失败 → "unknown"（页脚仍不出现）
```

禁止为欢迎页新建 `/api/models/ready`。禁止在未进入时打 `GET /api/models`。

页脚：`modelsReady === false` 时一行文字按钮「去设置添加模型」，打开 `SettingsDialog`（建议 `initialSection="models"`）。不画箭头、不写步骤 1/2。

进入 `ready` 之后，对话列不再出现 `workspace.getStarted` / `addModels` 块；相关 i18n key 可留着但无引用，或删掉以免再被接上。

### 4.2 点卡要不要 validate

与**当前下拉点最近项目**一致：直接采用 `root`，不先 `POST /api/cwd/validate`。自定义目录仍走 validate。今日目录仍走 `/api/default-cwd`。

目录已删：进入后文件树按现有错误显示；不在欢迎卡上预检。

`default-cwd` / validate 失败：`showToast({ tone: "error" })`，相位停在 `welcome`，不进三栏。

## 6. 工作包（可直接派工）

P4（记住进入）已取消。原 P1 单独落地会让人卡在无入口的欢迎页，故 **P1 与原 P2 合并为 WP-A**。

| WP | 内容 | 前置 | 建议分支 |
|----|------|------|----------|
| **WP-A** | 相位 + Suspense 壳 + 禁止自动选 cwd + 欢迎页 Picker + 次要操作 + 删引导 + modelsReady 页脚 | 无 | `feat/r01-welcome-gate` |
| **WP-B** | 同一 Picker 的 modal 宿主 + 左栏项目名按钮 + 删除窄下拉 | WP-A | `feat/r01-workspace-switcher` |

与 R-02：全局字栈（R-02 WP-T1）可先于或并行 WP-A；**左栏项目名字体与路径 12px（R-02 WP-T2）与 WP-B 改同一文件 `SessionSidebar.tsx`，应同一 PR 或 WP-B 之后立刻做 T2，禁止各改一版路径按钮。**

### WP-A 步骤

1. `page.tsx` 加上与 `--bg` 同色的 Suspense fallback。
2. 抽出 `displayCwd` / `PathLabel`。
3. 实现 `WorkspacePicker`（welcome 宿主即可先用）。
4. AppShell：无深链时不挂载侧栏；拉 sessions/home/modelsReady；相位按 §2。
5. 进入：写 `enteredCwd` → 挂载侧栏并传入该 cwd → `ready` → `restoreWorkspaceContext`。**不要** `replace(?cwd=)`。
6. 删除 getStarted 箭头 JSX。
7. 删除 sidebar 自动 `setSelectedCwd(projects[0])`。
8. 深链 session 找不到 → welcome；深链 cwd 失败 → 全屏错误 + 回欢迎。
9. `DirectoryPicker` / `default-cwd` 接到 Picker 按钮；失败 Toast。
10. L2：无 URL 打开必见欢迎；带 `?session=` 仍直达；已配模型不见页脚。

### WP-B 步骤

1. AppShell `switcherOpen`；左栏按钮只开模态。
2. 删 sidebar 项目下拉及相关 filter / 下拉内自定义路径。
3. 按钮脸改为项目名；完整路径进 `title`。
4. 模态 Esc / 关闭不改 cwd；点另一张卡走与欢迎页同一进入函数（换 cwd + restore）。
5. L2：运行中换项目不整页白屏；Esc 后仍在原项目。

## 7. 边界与失败（施工时对照）

| 场景 | 期望 |
|------|------|
| 无最近项目（全新机器） | 不画空卡；副题 + 两个次要按钮 |
| 列表 HTTP 失败 | `welcome-error` + 重试；不是「去加模型」 |
| models 探测失败 | 页脚不出现 |
| 真零配置（无 models.json 模型且无已登录供应商） | 页脚一行，点开设置 |
| 今日目录 API 失败 | Toast error，留在欢迎 |
| 自定义路径非法 | DirectoryPicker 内错误（现有）或 Toast，留在欢迎 |
| 手机宽度 | 同一欢迎页/同一模态，不另做一套 |
| 运行中点会话跳到其他 cwd | 保持现状；不必先开 Picker |
| 后台会话 | 换项目不杀（R-07）；本夹不改 rpc-manager |

| V5 | 「使用今日目录」 | 进入 `~/pi-cwd-YYYYMMDD` |
| V6 | `/?session=<真实 id>` | 不经过欢迎，直接该会话 |
| V7 | `/?session=<不存在>` | 回欢迎，不进某个默认仓库 |
| V8 | `/?cwd=<合法路径>` | 直达；非法路径全屏错误且能回欢迎 |
| V9 | 进入后点左栏项目名 | 模态，不是窄下拉；Esc 后 cwd 不变 |

| V12 | 今日目录或校验失败 | 欢迎页上看得到 error Toast（可在视口顶，不要求文件列锚点） |

- 与 04 线框一致：产品名淡、标题 20–22、次要按钮不是主色大块。

## 10. §决策记录（本轮为可施工而补的实现拍板）

04 的 D1–D7 不动。下列是把 04 落到代码时必须写死、避免施工再问的项。

| 项 | 决策 | 理由 |
|----|------|------|
| P1 能否单独上线 | **不能。** 与欢迎卡片合并为 WP-A | 只关门不给选，人进不去 |
| 欢迎页是否挂载侧栏 | **不挂** | 挂载就会跑自动选 cwd，露底复发 |
| 点最近项目是否 validate | **不。** 与现下拉相同 | 不加戏；自定义路径才校验 |

| 探测失败是否显示加模型 | **不显示**（`unknown`） | 禁止再把「还不知道」当成第一次用 |
| 深链 session 丢失 | **回欢迎**，不选 projects[0] | 与 D1 同一逻辑 |
| 深链 cwd 失败 UI | **全屏错误**，可回欢迎 | F-11；不塞进半成品三栏 |
| 设置页是否新开「模型」深链路由 | **不做。** 可选 `initialSection` 即可 | 复用现弹层 |
| 相对时间 | **复用 i18n `formatRelativeTime`** | 禁止第三套英文 ago |
| 手机 | **同一套 Picker** | 不加第二套 UI |
| 与 R-02 | **WP-B 与字体 T2 同文件协同** | 路径按钮只改一次 |
| 进入后写 `?cwd=`（PR-01） | **不写** | 否则刷新跳过欢迎 = 已撤销的「记住进入」 |
| `entering` 可见屏（PR-02） | **不画。** 点完直接 `ready`；吸收 `initialCwdStatus` | 不加戏；cwd 已知则架子和路径同到 |
