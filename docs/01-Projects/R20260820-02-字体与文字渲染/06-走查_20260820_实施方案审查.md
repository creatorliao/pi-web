## PR-F1 根因

好上手是「和本机 VS Code 并排」，不是「CSS 第一项写成 Windows 字体名」。

| 环境 | VS Code 默认 | Segoe/Consolas 写全球第一时 |
|------|--------------|------------------------------|
| Windows 未装 Menlo | Segoe + Consolas | 仍是 Segoe + Consolas |
| macOS 装了 Office（带 Segoe/Consolas） | SF + Menlo | 会变成 Segoe + Consolas，和旁边 Cursor 打架 |

不加戏：用一张静态栈，不写探测脚本。
