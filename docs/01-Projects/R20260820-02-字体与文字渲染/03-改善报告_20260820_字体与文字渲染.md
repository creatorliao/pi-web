## 推荐总图

**做「和本机 VS Code 坐在一起不打架」的字，不做品牌展示字。**

```text
--font-ui:   Segoe UI / 系统 UI / 中文系统黑体
--font-mono: 按平台 IDE 默认等宽（Win = Consolas）
Noto Sans Mono：退出全局等宽（或仅作为「本机全无等宽」时的最后回退，且不要 swap 换脸）
```

界面按钮、标题、项目名走 `--font-ui`。只有代码、输入里的代码、需要等宽对齐的 token 走 `--font-mono`。路径：主标签用 UI 字显示**最后一段目录名**（与 R-01 左栏改项目名一致）；完整路径用 12px 等宽或放进 tooltip。

## 推荐字栈（确认后写入 CSS）

**UI（Windows 优先写清，因当前用户在 Win10）：**

```text
Segoe UI, Segoe UI Variable, system-ui,
-apple-system, BlinkMacSystemFont,
"PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei",
sans-serif
```

**等宽：**

```text
Consolas, "Cascadia Mono", Menlo, Monaco,
"Courier New", ui-monospace, monospace
```

不把未安装的 `JetBrains Mono` / `Fira Code` 写在 Consolas 前面，避免制造「假默认」。

**渲染：**

- 不在全局开 `-webkit-font-smoothing: antialiased`（那是 macOS 习惯，Win 上会让 Segoe 变细、更像锯齿）。
- 等宽最小 12px；行高按 1.4～1.55，避免 11px 挤齿。
- 数字多的铬条可加 `font-variant-numeric: tabular-nums`，不必为此改等宽。

## 与「网上下载一张更圆的字」对比

| 方案 | 优点 | 代价 | 本夹态度 |
|------|------|------|----------|
| A 系统 UI + 系统等宽（推荐） | 和 VS Code 一致、零下载、无 swap、中文一体 | 「个性」弱 | **默认** |
| B 继续 Noto Mono + 加大字号 | 改动小 | 中文仍缺失、启动仍可能换字 | 不推荐当终态 |
| C 引入 Inter / Geist 做 UI | 部分落地页更「现代」 | 又一次 Web 字体、和 VS Code 并排违和 | 仅当确认要品牌脸 |

用户点名 VS Code，所以 A 是对题的。若确认后仍觉得 Consolas 偏「老」，再考虑本机已装的 Cascadia Mono（Win11 / 新终端常带），仍不要 Google Fonts 当主路径。
