## 写入时的字栈（确认后）

```text
--font-ui:   -apple-system, BlinkMacSystemFont, Segoe UI, Segoe UI Variable,
             system-ui, "PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei",
             sans-serif

--font-mono: Menlo, Monaco, Consolas, "Cascadia Mono", "Droid Sans Mono",
             "Courier New", ui-monospace, monospace
```

Win 上前几个系统名不存在，**观感仍是 Segoe UI + Consolas**（T-A 不变）。Mac 不会被 Office 自带的 Segoe/Consolas 抢走。顺序依据见 [06-走查 PR-F1](./06-走查_20260820_实施方案审查.md)。

- 等宽最小 12px；不在全局开 `-webkit-font-smoothing: antialiased`。
- 标题、按钮、项目名、欢迎标题走 `--font-ui`。
- 代码块、Composer 代码、需要对齐的 token 走 `--font-mono`。
- 栈里不把未安装的 JetBrains Mono / Fira Code 写在 Consolas 前面。
