## 问题 1：长文件不好滚

右侧文件区很长时几乎看不见滚动条。全局样式把滚动条做成 4px、颜色接近边框，Windows 上又常是「滑到才出现」。用户不知道还能滚、也不好抓。

成功标准：文件区（预览 / 源码）有稳定、好点的滚动条；不把整站其它面板的细滚动条一并加粗。

## 问题 2：系统提示词糊成一团

「系统提示词.md」现在把内核拼好的一整段塞进一个代码块。用户分不清哪一段来自 AGENTS.md、哪一段是技能清单、哪一段是 pi 默认约定。

调查结论（内核 `@earendil-works/pi-coding-agent` 的 `buildSystemPrompt`）：

1. **基础**：默认「You are an expert coding assistant…」或自定义 `customPrompt`
2. **追加**：`appendSystemPrompt`（设置 / 扩展追加）
3. **项目指令**：祖先目录与 `~/.pi` 上发现的 `AGENTS.override.md` / `AGENTS.md` / `CLAUDE.md`，包在 `<project_instructions path="…">` 里
4. **技能清单**：`<available_skills>`，每项指向一份 `SKILL.md`（正文不内联，要模型自己 read）
5. **工作目录**：末行 `Current working directory:`

成功标准：虚拟 Markdown 用标题 / 分隔线按上述来源切开；路径写在小节里。不改变发给模型的真实拼接。
