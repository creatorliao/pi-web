## 1. 滚动条

只加强 `.file-viewer-content`：

- 轨道始终占位（`scrollbar-gutter: stable`）
- 宽度约 10px，圆角滑块，颜色用 `text-muted` 与边框混合，悬停略加重
- Firefox 用 `scrollbar-width: thin` + `scrollbar-color`
- 不改全局 4px 规则，避免聊天区变丑

## 2. 提示词分区

在构造虚拟 md 时解析内核留下的 XML 标记，重排成 Markdown 小节（展示用，不回写 Agent）：

| 小节 | 识别 |
|------|------|
| 内核与工具约定 | 去掉下列块后的剩余文本 |
| 项目指令 · 文件名 | `<project_instructions path="…">` |
| 可用技能 | `<available_skills>` 每条 name/description/location |
| 工作目录 | 末行 `Current working directory:` |

项目指令正文按原 Markdown 嵌入；技能只列清单（与内核一致，SKILL.md 全文不在系统提示里）。
