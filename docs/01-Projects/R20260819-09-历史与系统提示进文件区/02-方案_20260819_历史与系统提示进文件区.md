## 1. 做法

路径约定（仅客户端身份，不落盘）：

- `pi-virtual://history/{sessionId}.md`
- `pi-virtual://system/{sessionId}.md`

标签带 `virtualContent`。`FileViewer` 见到虚拟内容就不再请求 `/api/files`，按 markdown 渲染。

- **历史**：`GET /api/sessions/[id]` 的 `context.messages` 拼成 Markdown（当前叶路径，和聊天看到的同一条线）。
- **系统提示**：复用已有 `get_state` 加载器，把返回的 `systemPrompt` 包进 Markdown。

「会话」菜单仍保留这两项入口，但行为改为打开文件区，不再展开下拉。

## 2. 验收

| ID | 标准 |
|----|------|
| V1 | 点「完整历史」→ 右侧出现 `完整历史.md`，无新浏览器标签、无顶栏下拉 |
| V2 | 点「系统」→ 右侧出现 `系统提示词.md`，无顶栏下拉 |
| V3 | 可用 FileViewer 预览 / 源码切换 |
| V4 | 关标签与普通文件一样；不产生磁盘文件 |
