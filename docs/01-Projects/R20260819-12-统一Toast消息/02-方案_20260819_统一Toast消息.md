## §1 判断

瞬时提示若画在触发它的控件里（空下拉、菜单项改字），控件语义就被结果污染。Toast 与控件解耦：菜单永远是动词，结果去视口底部说一句。

## §2 实现

| 文件 | 职责 |
|------|------|
| `lib/toast.ts` | `ToastTone` / `ShowToastOptions` 类型与默认时长 |
| `hooks/useToast.tsx` | `ToastProvider` + `useToast().showToast` |
| `components/ToastHost.tsx` | 底部居中、最多 3 条、`role="status"` |

语气：`info` / `success` / `error`。默认时长：info 5s、success 4s、error 8s（对齐 Carbon 5s、Sonner 4s；失败加长以便读完）。新条目顶替过期条目；同文案短时间去重，避免连点刷屏。

`app/page.tsx` 在 `I18nProvider` 内包 `ToastProvider`，同层挂 `ToastHost`。

## §3 调用约定

```ts
showToast({ message, tone?: "info" | "success" | "error" });
```

- 说明「现在做不成」→ `info`（无分支、会话未保存）。
- 操作完成 → `success`。
- 操作失败 → `error`，可带服务端短句。
- 禁止再为同一事件画空下拉或改菜单标签。

## §4 首批接入

| 场景 | 行为 |
|------|------|
| `⋯` / 工具条点「分支」，树无分叉 | `info`：`i18n.noBranches`；不 `toggleTopPanel("branches")` |
| 无活动会话时点「分支」 | `info`：`i18n.noActiveSession` |
| 手动生成标题进行中 | `info`：`title.generating`；菜单字不改 |
| 手动生成标题成功 | `success`：`title.updated` |
| 手动生成标题失败 | `error`：失败短句或 `title.failed` |
| 未保存 / 无消息时点生成标题 | `info`：对应原因；不发起请求 |
| 后台 `silent` 自动命名 | 不 Toast |

`sessionHasBranches()` 从 `BranchNavigator` 导出，与面板是否有内容用同一套判定。无内容时面板不再渲染斜体空态。

## §5 验收

1. 线性会话点「分支」：底部 Toast，无下拉空层。
2. 有分叉时：仍打开原分支树。
3. 点「生成标题」：菜单字始终是「生成标题」，结果只出现在 Toast。
4. 深浅色都用 `--bg-panel` / `--text` / `--border` / `--accent`，不另起一套色。
5. 位置在文档区顶部居中；外形为胶囊（随字宽、`999px` 圆角），不是满宽方块。
