## 什么叫「低垂果实」

同时满足四条才算，缺一条就降档：

| # | 条件 | 判据 |
|---|------|------|
| 1 | **改动面小** | 大约一个文件族、百行量级或纯 CSS/文案；不新开子系统 |
| 2 | **风险可控** | 失败形态可测；不改会话 jsonl / 内核生命周期 / 鉴权密钥选择 |
| 3 | **用户立刻有感** | 对齐「能用、好看、少点一下、少背概念」 |
| 4 | **本仓还没做完** | 对照过当前树；已有等价实现的不列入 |

**不是低垂**：看起来一行能改、但会误伤 CSRF、误杀子进程、误重试计费请求、或把终端/PWA 拖进默认壳。

本仓抽查结论（避免重复摘）：`bin/process-lifecycle.js` 已转发信号且不用 `code ?? 0`（[#506](https://github.com/agegr/pi-web/issues/506) / [#515](https://github.com/agegr/pi-web/pull/515) 故事多半已落地）；`lib/project-command-env.ts` 已剥离 `PORT`/`NODE_ENV`（[#484](https://github.com/agegr/pi-web/issues/484)）。这两条**不再当果实**。

## 结论先行：建议先摘的一篮（约 1～3 个小 WP 就能扫完）

按「对普通用户的收益 / 工程成本」排序。带 ★ 的是**既低垂又打在致命或高频体验上**。

| 序 | 项 | 上游 | 本仓现状 | 预估 | 风险 | 为何算果实 |
|----|----|------|----------|------|------|------------|
| 1 ★ | 本机 403：Origin 丢端口 | [#542](https://github.com/agegr/pi-web/issues/542) · PR [#544](https://github.com/agegr/pi-web/pull/544) | `lib/request-security.ts` 仍 `canonicalOrigin(origin) === requestOrigin`（含端口） | 半日：改比较逻辑 + 补测 | **安全敏感但可测** | 新 Chrome/Edge 可能整页废掉；补丁上游已写好测例思路 |
| 2 | 顶栏够宽仍折叠 | [#525](https://github.com/agegr/pi-web/issues/525) · PR [#549](https://github.com/agegr/pi-web/pull/549) | `AppShell` 已有 mobile toolbar，「空间够仍折叠」是断点阈值问题 | 数小时 | 低（布局） | 0.8.9 用户已骂；少一次「更多」就更像正常软件 |
| 3 | 长提示被裁切 | [#524](https://github.com/agegr/pi-web/issues/524) | 多处 `overflow: hidden` / 单行 | 数小时 CSS | 极低 | 纯排版，直接服务「大方可读」 |
| 4 | 扩展状态条换行 / 可点 | [#538](https://github.com/agegr/pi-web/issues/538) · [#535](https://github.com/agegr/pi-web/pull/535) [#539](https://github.com/agegr/pi-web/pull/539) | 独立小组件 | 数小时 | 极低 | 小 diff；装插件的用户立刻能点 |
| 5 | `pi-web --help` | [#521](https://github.com/agegr/pi-web/issues/521) | `bin/pi-web-options.js` 已解析端口等，入口未见 help | 1～2 小时 | 极低 | 降低「装完不知道怎么开」的成本；不进界面 |
| 6 | 技能开关写坏 `false` | [#519](https://github.com/agegr/pi-web/pull/519) | `app/api/skills/route.ts` 用 `Boolean(frontmatter[key])`，显式 `false` 会被当成未设置再插一行 | 数小时 + 单测 | 低（只改 frontmatter 一行逻辑） | 用户关技能却弄坏 SKILL.md |
| 7 | 用户消息大图重复渲染 | [#533](https://github.com/agegr/pi-web/pull/533) | 限 `MessageView` | 半日 | 低 | 卡顿/叠图，用户以为界面脏 |
| 8 | 繁体中文 | [#508](https://github.com/agegr/pi-web/issues/508) · PR [#512](https://github.com/agegr/pi-web/pull/512) | `registry` 只有 `en` / `zh-CN`，`zh-TW` 会落到简体或英语 | 翻译劳动大、**技术风险低** | 低 | 华语用户门槛；可抄上游文案再审 |

**建议第一摘：1★ + 2 + 3。** 三天内能同时抬「能打开」和「看起来正常」。8 可并行（人肉翻译），不挡开发。

| 代理 Origin scheme [#497](https://github.com/agegr/pi-web/issues/497) / [#511](https://github.com/agegr/pi-web/pull/511) | 与 ★1 同类改 `request-security`，可**同一 PR 做完**；单独做远程隧道不是一期必摘。风险仍是 CSRF，必须跟 Host 校验绑在一起测。 |
| 粘贴资源管理器路径 [#529](https://github.com/agegr/pi-web/issues/529) / [#536](https://github.com/agegr/pi-web/pull/536) | Windows 很值，但 +478、碰输入框与 cwd API，和本仓 Cursor 化输入框叠车，要设计评审 |
| 钉住自定义项目路径 [#543](https://github.com/agegr/pi-web/pull/543) | 故事对（找得到项目），+318 还算可控；要和侧栏/本仓布局 R 对齐，避免两套「最近项目」 |
| 文件区最大化 [#548](https://github.com/agegr/pi-web/pull/548) | 体验对，必须并进 R20260819-03，禁止平行做第二套最大化 |

## 明确不是低垂（再强调，避免被「也挺想要」拖进第一波）

| 项 | 原因 |
|----|------|
| Stop 卡死 [#368](https://github.com/agegr/pi-web/issues/368)、泄漏 [#546](https://github.com/agegr/pi-web/issues/546)、空 aborted [#351](https://github.com/agegr/pi-web/issues/351) | 内核竞态 / 生命周期；错修会丢消息或杀不掉工具 |
| DeepSeek 静默 Key [#486](https://github.com/agegr/pi-web/issues/486) | 资金与信任；要全路径审计，不是小补丁 |
| 提问卡 [#510](https://github.com/agegr/pi-web/pull/510)、MCP 面板 [#470](https://github.com/agegr/pi-web/pull/470)、PWA 全家桶 [#551](https://github.com/agegr/pi-web/pull/551)、语音 [#483](https://github.com/agegr/pi-web/pull/483) | 价值高、面大，是路线图项不是果实 |

```text
安全可测小补丁     看得见的排版/顶栏     零概念 CLI/文案
   ★ Origin 403  →  #525 + #524 + 扩展条  →  --help / 繁体
        ↓
   同一文件顺手做隧道 scheme（若你确认要远程）
        ↓

```
