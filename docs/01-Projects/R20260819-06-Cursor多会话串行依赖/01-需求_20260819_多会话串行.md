# 需求：多会话按依赖串行、不同上下文、人不值守

## 背景

你是 Cursor 重度用户，会同时开多个 Agent 会话。有些工作在前序未完成前，后序会话**不该启动**（文件未就绪、分支未合入、调查结论未出）。当前只能自己盯着机器：前序跑完再手动点开下一聊。

## 目标

1. **串行门禁**：后序任务在前序「完成条件」满足前不开始。
2. **上下文隔离**：后序仍是独立对话/独立上下文，不被前序长对话挤爆。
3. **不值守**：前序跑完后，后序能自动或半自动启动（可关电脑或去干别的）。
4. **可复盘**：谁在等谁、何时放行，有痕迹。

## 约束

- 优先用 **Cursor 官方能力**，少造轮子。
- 本机 IDE 会话与云端 Agent 可混用，但要说清边界。
- 完成条件可能是：Agent 正常结束、PR 合并、CI 绿、某文件/标记出现。

## 非目标

- 不要求官方立刻做一个「聊天队列」产品（调查结论会写清缺口）。
- 不把「同一会话里连续追问」当成已满足「不同上下文」。
- 本期不改 `pi-web` 产品代码。
