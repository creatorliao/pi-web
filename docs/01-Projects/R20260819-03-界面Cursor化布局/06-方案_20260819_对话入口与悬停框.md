## §1 一条铁律

**顶栏只导航。文件名只出现一次。审阅状态走底部细栏。列表用推挤，不用遮挡。**

| 列 | 只允许的 chrome | 禁止 |
|----|-----------------|------|
| 中间文件顶栏 | **一行导航**：左栏开关 + 会话 + 页签 + 收紧右侧 | 再画一行空顶栏；把 Source/Preview/`@`/下载挂进顶栏 |
| 中间文件底栏 | **一条细状态栏**（约 24px）：原文档/预览/来源 + 审阅操作 | 做成第二套 36px 标题；再写一遍文件名 title |
| 右侧对话（编辑器） | 对话顶栏：右对齐 `[ + ] [列表抽屉]` | 再叠一层文字头；用时钟；打开列表时藏掉当前对话 |

叠层 title、收起靠左、时钟、列表盖住对话，都是同一条铁律被打破。

## §2 目标桌面（编辑器默认）

```text
┌─ 左栏 ──────┬─ 中间文件 ─────────────────────┬─ 右侧对话栏 ──────────────────┐
│ 项目 / 目录  │ 一行导航：开关 + 会话 + 页签 + 收紧 │ 对话顶栏：[ + ] [列表]        │
│             │ 正文（无第二 title）            │ ┌─ 当前对话 ──────┬─抽屉 240─┐ │
│             │ ← 打开列表时被挤窄               │ │ 被推向左侧      │ 会话列表 │ │
│             │ 底栏：原文档/预览 · 操作（细）   │ └─────────────────┴──────────┘ │
└─────────────┴───────────────────────────────┴────────────────────────────────┘
```

助手布局：中间是对话。`[ + ] [侧栏]` 挂在**中间主顶栏最右**，对话块不再另起标题行。抽屉仍在对话块**内部**左抽。右侧文件列同样：页签一行，无叠 title。

手机不改信息架构。

## §4 对话块

### 4.1 顶栏

右对齐两组，中间不放标题字：

1. `+`：新建对话（无 cwd 时禁用）
2. 侧栏面板：开关列表抽屉（`aria-pressed` 反映开合）

编辑器：画在右侧对话栏顶。助手：画在中间主顶栏最右。文件页签行**禁止**再挂这两枚。

### 4.2 抽屉

```text
关：  [ 中间文件（宽） ][ 当前对话 ]
开：  [ 中间文件（窄） ][ 当前对话（左移） ][ 列表 240 ]
```

- 对话栏内部横向 flex：**先对话、后列表**。
- 编辑器打开列表时，`--right-panel-width` 临时 +240（不写入记忆宽度），中间文件被挤窄。
- 对话列始终挂载，禁止 `display:none` / 遮罩。
- 列表宿主关时宽度为 0，仍留在 DOM。

### 4.3 整栏显隐

`rightPanelOpen` 关掉整块右侧（对话+列表）。开关画在**中间主顶栏最右**（与「会话」、文件页签同一行），对话栏开着时也在。图标用右轨侧栏图，和对话栏上的列表键（左轨）区分。文件列不再另起一行标题。

## §5 文件页签（对齐 VS Code）

页签已有的行为保持：单击切换、关闭钮、中键关闭、横向溢出滚动。本轮**不**做钉选、预览页签、分栏编辑。

改的是 chrome：

| 现在 | 改后 |
|------|------|
| 页签行写文件名 | 只在这里写文件名 |
| 下一行 `FileViewer` 再写路径 + `markdown · N lines · size` | **删掉**路径和体积行 |
| Source / Preview / Diff / `@` / 下载在顶栏 | 搬到**文档底部细状态栏**右侧 |
| 是否原文档 / 来源 / 语言 | 底栏左侧，11px 弱化，不写文件名 title |

实现（复用优先，不把模式状态搬出 `FileViewer`）：

1. 顶栏页签行不再挂 `fileChromeHost`。
2. `FileViewer` 各文档页自己画底部 `file-viewer-statusbar`：左侧来源/视图，右侧操作。
3. **永不**再画顶部文件名 title；文件名只在页签。

空文件工作区：只有空态文案，没有假标题行。
