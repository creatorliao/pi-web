## §1 一条铁律

**顶栏只导航。文件名只出现一次。审阅状态走页签正下方细栏。列表用推挤，不用遮挡。**

| 列 | 只允许的 chrome | 禁止 |
|----|-----------------|------|
| 中间文件顶栏 | **一行导航**：左栏开关 + 会话 + 页签 + 收紧右侧 | 再画一行空顶栏；把 Source/Preview/`@`/下载挂进顶栏 |
| 中间文件次栏 | **页签正下方**一条细状态栏（约 24px）：原文档/预览/来源 + 审阅操作 | 做成第二套 36px 标题；贴到窗口最底；再写一遍文件名 title |
| 右侧对话（编辑器） | 对话顶栏：右对齐 `[ + ] [列表抽屉]` | 再叠一层文字头；用时钟；打开列表时藏掉当前对话 |

叠层 title、收起靠左、时钟、列表盖住对话，都是同一条铁律被打破。

## §2 目标桌面（编辑器默认）

```text
┌─ 左栏 ──────┬─ 中间文件 ─────────────────────┬─ 右侧对话栏 ──────────────────┐
│ 项目 / 目录  │ 一行导航：开关 + 会话 + 页签 + 收紧 │ 对话顶栏：[ + ] [列表]        │
│             │ 正文（无第二 title）            │ ┌─ 当前对话 ──────┬─抽屉 240─┐ │
│             │ ← 打开列表时被挤窄               │ │ 被推向左侧      │ 会话列表 │ │
│             │ 页签下细栏：原文档/预览 · 操作   │ └─────────────────┴──────────┘ │
└─────────────┴───────────────────────────────┴────────────────────────────────┘
```

助手布局：中间是对话。`[ + ] [侧栏]` 挂在**中间主顶栏最右**，对话块不再另起标题行。抽屉仍在对话块**内部**左抽。右侧文件列同样：页签一行，无叠 title。

手机不改信息架构。

## §4 对话块

### 4.1 顶栏

右对齐两组，中间不放标题字：

1. `+`：新建对话（无 cwd 时禁用）
2. 侧栏面板：开关列表抽屉（`aria-pressed` 反映开合）

编辑器：画在右侧对话栏顶。助手：画在中间主顶栏最右。文件页签行**禁止**再挂这两枚。

### 4.2 抽屉

```text
关：  [ 中间文件（宽） ][ 当前对话 ]
开：  [ 中间文件（窄） ][ 当前对话（左移） ][ 列表 240 ]
```

- 对话栏内部横向 flex：**先对话、后列表**。
- 编辑器打开列表时，`--right-panel-width` 临时 +240（不写入记忆宽度），中间文件被挤窄。
- 对话列始终挂载，禁止 `display:none` / 遮罩。
- 列表宿主关时宽度为 0，仍留在 DOM。

### 4.3 整栏显隐

`rightPanelOpen` 关掉整块右侧（对话+列表）。开关画在**中间主顶栏最右**（与「会话」、文件页签同一行），对话栏开着时也在。图标用右轨侧栏图，和对话栏上的列表键（左轨）区分。文件列不再另起一行标题。

## §5 文件页签（对齐 VS Code）

页签已有的行为保持：单击切换、关闭钮、中键关闭、横向溢出滚动。本轮**不**做钉选、预览页签、分栏编辑。

改的是 chrome：

| 现在 | 改后 |
|------|------|
| 页签行写文件名 | 只在这里写文件名 |
| 下一行 `FileViewer` 再写路径 + `markdown · N lines · size` | **删掉**路径和体积行 |
| Source / Preview / Diff / `@` / 下载在顶栏 | 搬到**页签正下方细状态栏**右侧 |
| 是否原文档 / 来源 / 语言 | 该细栏左侧，11px 弱化，不写文件名 title |

实现（复用优先，不把模式状态搬出 `FileViewer`）：

1. 顶栏页签行不再挂 `fileChromeHost`。
2. `FileViewer` 各文档页在正文**上方**画 `file-viewer-statusbar`：左侧来源/视图，右侧操作。
3. **永不**再画顶部文件名 title；文件名只在页签。

空文件工作区：只有空态文案，没有假标题行。

## §9 滚动条、分栏与级联收起（PR-10）

先把两样东西拆开，避免再把「滚动条」当「拖拽条」：

| 控件 | 在哪 | 干什么 | 长什么样 |
|------|------|--------|----------|
| 滚动条 | **栏内**右缘，压在内容上 | 只滚内容 | overlay 细条，空闲隐、悬停/滚动显 |
| 分栏条 | **两栏之间** | 改列宽 / 级联收起 | 12px 热区，空闲看不见线，悬停才出 2px 提示 |

### 9.1 滚动条（F-28 / F-29）

一套 class（建议 `overlay-scroll`），三处共用：文件正文、对话消息列、历史列表。

- 不占位：去掉文件区 `scrollbar-gutter: stable` 和 10px 加粗轨。
- 宽度约 6px，颜色用 `--text-muted` 低对比，圆角。
- 显现：指针在该滚动容器上，或该容器正在滚动；离开且停止滚动约 800ms 后淡出。
- 横向条：文件源码继续禁止（F-27）；对话/历史也只纵向。
- 对话列：删掉 `[scrollbar-width:none]`，否则 Firefox 永远无条。
- 左栏目录树也用同一套 overlay，避免三栏三张脸。

### 9.2 历史抽屉可拖（修订 D7）

对话 | 历史 之间加一条与现有 `panel-resize-handle` 同类的热区，`growthDirection: left`。

| 项 | 值 |
|----|----|
| 默认 | 240 |
| 最小 | 180 |
| 最大 | 360 |
| 记忆 | `pi-agent-history-width` |
| 打开动画 | 仍约 200ms；**拖的时候停 transition**，避免跟手迟滞 |

向左拖：先吃对话列多余宽度；对话已到安全宽（320）时，再把右栏总宽加大、从中间文件借。

### 9.3 往右压的级联（F-30）

拖的是 **文件 | 右栏** 那条分栏（不是滚动条），方向往右 = 右栏变窄。

对话安全宽 **320**（历史开着时，对话列不允许被压过这条线，除非历史已经关掉）。

```text
右栏总宽 = 对话宽 + (历史开 ? 历史宽 : 0)

往右拖：
  1) 历史开着且历史宽 > 180  → 先减历史宽
  2) 历史已到 180 还继续往右 → 关掉历史（腾出整段历史宽给对话，对话回到安全宽）
  3) 历史已关，继续往右     → 减对话宽，下限 320（对话安全宽，取代现 300）
  4) 再往右越过吸附        → 整栏收起（等同顶栏「收紧右侧」）
```

往左拖（加宽右栏）：只加对话宽或按现有 max 夹紧。**不自动重新打开历史**（仍点列表图标，沿用 D4）。

松手才写入：`pi-right-panel-width`、`pi-agent-history-width`、`agentHistoryOpen` / `rightPanelOpen`。拖过吸附后应用现有整栏关闭入口，顶栏图标仍能打开。

### 9.3b 左栏往左压（F-31）— 现状不满足，补进同一套手感

拖的是 **目录 | 中间** 分栏，往左 = 目录变窄。

```text
往左拖：
  1) 宽 > 200     → 只减目录宽
  2) 已到 200 还继续，指针暗示宽度 < 160
                  → 松手收起整栏（sidebarOpen=false，等同顶栏左栏开关）
  3) 未过 160     → 回弹停在 200，不关
```

- **不**在拖的过程中把宽度写成 160 存进 `pi-sidebar-width`。记住的永远是上次合法可见宽（≥200），下次打开还是 240 或用户拖过的宽度。
- 往右加宽**不**自动打开已收起的目录，仍点顶栏左侧开关。
- 键盘：Home 落到最小可见宽 200；再按一次 Home 或继续左方向键越过吸附才关。避免误触一键消失。

左右对称口诀：**先瘦到能用的最小，再越界才收起；打开只靠图标。**

### 9.7 出厂列宽（F-32）

编辑器默认「中间看文件」是主角。现默认右栏 42% 是旧「中间对话」配比，笔记本上再打开历史会把文件列压穿。

| 列 | 出厂默认 | 最小可见 | 吸附关闭 | 最大 |
|----|----------|----------|----------|------|
| 左 · 目录 | **240**（现 260） | 200（现 180） | 指针 < 160 | **360**（现 480） |
| 中 · 文件 | 吃剩余 | 安全宽 **420** | 不拖关 | — |
| 右 · 对话 | `clamp(视口×24%, 360, 420)`（现 ×42% → 574/640） | 320 | 历史已关且再越界 | **560**（现 1200） |
| 右 · 历史 | 240 | 180 | 先于对话关闭 | 360 |

视口验算（历史关 / 开）：

| 宽 | 左 | 对话 | 历史关时中间 | 历史开时中间 |
|----|----|------|--------------|--------------|
| 1366 | 240 | 360 | ~766 | ~526 |
| 1920 | 240 | 420 | ~1260 | ~1020 |
| 1280 | 240 | 360 | ~680 | ~440 |

1280 开历史时中间约 440，仍高于文件安全宽 420。已写入 `localStorage` 的旧宽度**不强制改写**；双击分栏恢复上表出厂值。

`getSidebarMaxWidth` / `getRightPanelMaxWidth` 里留给中间的常量应改用文件安全宽 420（现名 `DESKTOP_CHAT_MIN_WIDTH`，语义已过时）。

### 9.4 方案自审（功能完整 · 体验）

| 场景 | 预期 | 会不会坏 |
|------|------|----------|
| 短文件 / 短对话 | 无条或隐条 | 不占 gutter，不挤正文 |
| 长文件 Source | 悬停见细纵条，无横条 | 与 F-27 同时成立 |
| 长对话 | 右缘可发现、可拖滚动条 | 不再 `scrollbar-width:none` |
| 长历史列表 | 同样 overlay | 和对话同一套 class |
| 历史关着拖分栏 | 只改对话宽，到最小再关整栏 | 与现在接近 |
| 历史开着往右拖 | 先瘦/关历史，对话不先被压扁 | 安全空间 |
| 误把滚动条当拖栏 | 滚动条在栏内、分栏在缝上 | 视觉分离后误操作下降 |
| 松手回弹 | 未过吸附则回最小合法宽 | 不「拖一下整栏消失」 |
| 刷新 | 历史宽、右栏宽、开合记住 | 可追溯 |
| 助手布局 | 中间对话同样 overlay；右侧文件同样 | 一份 class |
| 手机 | 不改；仍抽屉/系统滚动 | 明确 Out of Scope |
| 键盘 | 方向键/Page 仍滚；分栏仍有 aria | 不依赖「看见条」才能滚 |
| 无障碍 | 滚动条可淡，不 `pointer-events:none` 掉点击 | 显现时仍能点到 thumb |
| 左栏往左拖过吸附 | 整栏收起，中间变宽 | 现在做不到，本方案补上 |
| 左栏未过吸附 | 停在 200，不关 | 防误关 |
| 1366 默认、历史关 | 左 240 · 中 ~766 · 右 360 | 中间是主角 |
| 1366 默认、历史开 | 左 240 · 中 ~526 · 右对话 360 · 历史 240 | 中间仍 ≥ 420 |
| 1920 默认 | 左 240 · 中 ~1260 · 右 420 | 对话不再占 42% |

**不做**：Cursor 拖拽时的亮蓝分栏；滚动条本身可当 resize；自动重开历史或目录。

### 9.6 决策记录

| 待决项 | 决策 | 理由 |
