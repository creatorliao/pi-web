## 用户原话

1. 对照 Cursor 深色 Agents 面板：新增对话在**对话顶部标题栏**，标题、加号、更多选项放在同一行。
2. 历史对话面板顶部要有空间：新增、搜索、工具栏，看起来更协调。
3. 历史按当天等时间分组；展示一部分后用**图标 + More** 展开。
4. 跟会话相关的下拉（完整历史 / 生成标题 / 分支 / 系统）**不要占页签区间**；放到对话顶部三个点。
5. 「会话」两个字不要了。
6. 补充痛点：**创建新对话不方便**；整体**不美观、不协调**。
7. 页签下细栏左侧的「磁盘文件 / 预览 / markdown」没有意义；更希望展示**文档路径**。
8. 对照 Cursor：对话是独立视觉区，`+` / `⋯` 在**对话面板顶部**。我们现在这两枚和列表键画在整块右栏顶上，历史一开就和搜索栏混成一条。
9. 细栏路径不一致：打开完整历史能看到 `pi-virtual://history/…`，打开目录里的文件却只显示文件名（页签已经有了）。要确定性的完整路径。

## 问题报告 PR-11

### 表层现象

编辑器默认布局下，右侧对话栏顶是一条几乎空白的 36px 横条，两个图标挤在最右；中间文件顶栏却挂着「⋯ 会话」像一枚假页签。历史抽屉打开后直接铺列表，没有搜索、没有新建、没有「今天」。要新建时，人必须先找到那枚孤独的 `+`；一旦整栏收起，`+` 跟着消失。

### 根因

| 层 | 说明 |
|----|------|
| 表层 | 新建入口少、难找；chrome 语言不统一；历史不可扫。 |
| 直接原因 | 1）`+` / 列表只画在 `agentWorkspace` 顶栏，整栏收起后入口为零。2）`renderSessionToolsButton` 画在中间主顶栏，带「会话」字，和文件页签抢同一行。3）历史门户只 portal 列表本体，没有自己的工具栏。4）`sessionTree` 按 fork 树平铺，无日期桶、无截断。5）对话顶栏按 D3 故意不放标题，留下一条空轨。 |
| 根本原因 | P1 / PR-02～10 解决的是「入口挂错行、列表遮挡、叠两层顶栏」。当时把对话顶栏做成**纯图标轨**，把会话工具塞进**文件导航行**，是为了少占字。结果对话窗不像一扇窗、历史不像一本目录、页签不像文件。新建变成「先找到对的窗，再点角落的十字」。 |

### 修复方向

把 chrome 按职责切开：**页签只放文件名；细栏只放路径；对话窗有自己的标题栏；历史抽屉有自己的工具栏与时间分组。** 新建在「栏开着 / 栏收起 / 正在翻历史」三条路上都找得到。

### 是否临时缓解

否。不改信息架构，只加一个快捷键提示也治不好「栏一关入口就没了」和「空顶栏 + 假页签」的不协调。

## 问题报告 PR-11b（细栏标签无意义）

### 表层现象

打开 Markdown 时，页签正下方细栏左侧写着「磁盘文件 · 预览 · markdown」。右侧已经有绿点、Source/Preview 分段、`@`、下载。左侧三词不回答「这是哪份文件」。

### 根因

| 层 | 说明 |
|----|------|
| 表层 | 细栏左侧是分类标签，不是位置。 |
| 直接原因 | `FileViewerStatusBar` 的 `meta` 画了 `originLabel`（磁盘文件/生成）、`viewLabel`（原文档/预览/对比）、`language`。相对路径只塞在「磁盘文件」的 `title` 里，悬停才看得到。图片/二进制细栏同样套路。 |
| 根本原因 | PR-08 为对齐 VS Code、避免再画一行文件名 title，把「是否原文档 / 来源 / 语言」塞进细栏左侧（06-方案 §5）。这三词和右侧控件**重复**：视图模式右侧已有 Source/Preview；语言在页签文件名后缀里；「磁盘文件」对普通打开几乎恒真。路径才是页签文件名给不了的信息（同名 `README.md`、深处的 `docs/01-Projects/…`）。 |

### 修复方向

细栏左侧改展示**相对项目根的路径**。右侧审阅控件不动。不把路径做成第二条 36px 标题。

### 是否临时缓解

否。只改 tooltip 救不了「第一眼看到的是废话」。

## 问题报告 PR-11c（顶栏横跨对话与历史）

### 表层现象

打开历史后，`+`、`⋯`、列表键坐在一条贯穿「对话 + 历史」的灰条上。历史自己的搜索栏在这条共享顶栏下面，两块面板不像两个独立区域。

### 根因

`data-agent-chrome` 是 `agentWorkspace` 里、横向 flex **之上**的兄弟节点，宽度等于对话列 + 历史列。D19 把三枚图标放进这一行，历史开着时它们必然压在分界线上。

### 修复方向

标题栏只画在**对话列**顶。历史列自己的 36px 头放搜索和收起列表。列表开着时，对话顶栏只留 `[+] [⋯]`。

## 成功标准

1. 不打开历史、不打开整栏，也能一键进入新对话（栏关着走主顶栏 `+`）。
2. 打开历史后，不用把视线挪回对话顶栏也能新建、能搜标题。
3. 文件页签行再也看不到「会话」二字，也不会误以为多开了一个叫「会话」的文件。
4. 一眼能分辨：这是今天的对话，还是更早的；列表不会一屏铺满几十条。
5. 对话栏顶不再是一条空轨：有标题、有主操作、有溢出，和 Cursor 深色 Agents 窗的节奏同类（不要求像素复制）。
6. 打开文件后，细栏左侧能读到这份文档在项目里的路径；不再出现「磁盘文件 / 预览 / markdown」三词并排。
7. 打开历史后，对话顶栏的 `+` / `⋯` 只压在对话列上；历史列顶是自己的搜索/收起，两条轨对齐但不共用。

## 非目标

- 不复刻 Cursor 的 Search Agents 产品语义、Customize、Ctrl+N 文案、太阳/对勾状态图标、蓝点未读样式。
- 不把历史改回浮层 / 最左栏；抽屉推挤、可拖宽、级联收起（D1 / D7 / D13）保持。
- 不改手机抽屉信息架构（手机已有独立 more 条）。
- 不在本轮做会话重命名就地编辑、钉选、多选删除。
- 不把 fork 树打平丢掉：子会话仍挂在父会话下，只对**根会话**做日期分组。
