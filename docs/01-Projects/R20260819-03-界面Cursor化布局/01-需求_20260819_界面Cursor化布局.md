## 用户原话（收束）

1. 界面有些地方**太偏向程序员**，希望普通大众也能用。
2. 该进设置的进设置，主界面重新优化。
3. 整版与使用习惯对齐**通用产品**，本人是 **Cursor 重度用户**，整体风格优先对齐 Cursor。
4. 习惯：**目录树在左，对话在右，中间看文件**；历史对话与对话过程也在右边。
5. 重点是**元素排布**：历史位置、新增对话方式、审查文档、目录树位置。
6. 保留用 Cursor 智能体的习惯，同时用上 pi-web 现有能力。
7. Cursor 独有、难复刻的能力**不必硬仿**；本轮只关心壳层排布与信息层级。
8. 先调查、给方案、**等确认，不要马上执行**。
9. **增量（2026-08-19）**：有人更希望**在中间输入**；本人可能是特例。希望论证能否**同时兼容两种 UI，并在设置里切换**；先记录，再综合完善方案；代价太大要明说。

## 目标（Why + What）

- **业务目标**：默认手感对齐 Cursor「编辑器窗口」；同时承认「中间说话」是另一群人的熟布局，用**设置切换**兼容，而不是强迫所有人跟你走。
- **用户价值**：少学一套新空间；日常任务不必先读懂 session / cwd / token；换习惯的人不用装两套产品。
- **成功标准**：见下方 F-01～F-11；程序员细节仍可在设置里找到，主界面默认不挡路。

## 功能需求（In Scope）

| # | 需求描述 | 优先级 | 来源 |
|---|----------|--------|------|
| F-01 | 桌面**默认**三栏（编辑器布局）：**左目录树（+ 项目）· 中文件工作区 · 右对话** | 必做 | 用户习惯 |
| F-02 | 编辑器布局下：**历史**与**当前过程**跟对话块在一起（默认在右），不与中间审阅抢位 | 必做 | 用户 |
| F-03 | **新建对话**的主入口跟对话块走（编辑器布局在右栏顶），不依赖「必须先在左侧点会话」 | 必做 | 用户 |
| F-04 | 编辑器布局下：从目录树、对话链接打开的文件在**中间栏**以标签页审阅 | 必做 | 用户 |
| F-11 | 设置里可在两种工作区布局间切换，并持久化；默认仍是编辑器布局。兼容深度见方案分档（槽位切换 vs 两套信息架构） | 应做 | 增量：中间输入人群 |
| F-05 | 主界面默认隐藏程序员向只读信息（会话 uuid、jsonl 路径、token/cache、系统提示全文等），改到设置或「高级」 | 必做 | 大众化 |
| F-06 | 目录树默认不铺开构建产物与依赖目录（如 `.next`、`node_modules`），设置里可打开「显示隐藏/忽略项」 | 应做 | 大众化 + 截图痛点 |
| F-07 | 顶栏不再堆「完整历史 / 生成标题 / 分支 / 系统」一排工程按钮；会话级工具收入右侧菜单或设置 | 应做 | 对齐 Cursor 干净顶栏 |
| F-08 | 文案面向任务：会话→对话、cwd 路径→项目名；等宽绝对路径不作为默认主展示 | 应做 | 大众化 |
| F-09 | 设置增加「外观/布局」与「高级」分层：大众项与开发项分开 | 应做 | 用户「放到设置」 |
| F-10 | pi 独有能力保留但降噪：会话内分支、Fork 树、worktree、工具预设、压缩上下文——不删能力，不占主视觉 | 必做 | 用户「不必复刻 Cursor 独有，但保留自己的」 |

## 非功能需求

- 桌面优先对齐；手机可继续抽屉，不在本 R 重做移动端信息架构。
- 沿用现有 CSS 变量与 i18n，不新开视觉体系。
- 布局宽度、侧栏开关仍可拖拽/记忆（已有 `pi-sidebar-width` 等）。
- 不做 `next build`。

## 非目标（明确不复刻 / 本轮不做）

| 不做什么 | 理由 |
|----------|------|
| Cursor Glass / Agents 独立窗口、双窗口切换 | Cursor 3 产品壳，不是本仓库能力边界 |
| Agent Stats / Tab Stats / 底栏 Git / 终端 | 用户点名不要程序员仪表盘 |
| 命令面板当主导航、多根工作区、扩展市场 | 难复刻且非本轮排布 |
| 输入框再改一版 Composer | 已在 R20260819-01 |
| 改 Agent 内核、会话 jsonl 格式 | 壳层问题 |
| 把 ChatGPT「中间对话」设成**出厂默认** | 与发起人的 Cursor 习惯冲突；可作设置项，不作默认 |
| 完整复刻两套信息架构（历史左 vs 历史右各写一套导航） | 代价见方案；默认不纳入本 R，除非 Gate-S 点名要 C 档 |

## 约束

- 复用 `AppShell`、`SessionSidebar`、`ChatWindow`、`FileViewer`/`TabBar`、`SettingsDialog`，以搬家和显隐为主，不新造第四套壳。
- 会话数据源、`startRpcSession`、SSE 契约不变。
- 与 R20260819-01 输入框可并行，避免同时大改 `ChatInput` 布局逻辑。
